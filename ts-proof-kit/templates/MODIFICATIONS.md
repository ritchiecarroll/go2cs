This repository is a derivative of part of the Go source of TypeScript, `github.com/microsoft/TypeScript/tsc` in
[microsoft/TypeScript](https://github.com/microsoft/TypeScript/tree/ba29a562991ceb942481e2a00810b4e5e4062e52/tsc)
at commit `ba29a562991ceb942481e2a00810b4e5e4062e52`, licensed under the Apache License 2.0 ([LICENSE](LICENSE)),
with its [NOTICE.txt](NOTICE.txt) carried verbatim. As section 4 of that license requires, this file states what was
changed.

## Changed: every C# file under `src/github.com/microsoft/TypeScript/tsc/internal/`

Each `.cs` file there is a machine translation, by [go2cs](https://github.com/ritchiecarroll/go2cs), of the Go file
of the same name in the TypeScript package of the same path. Each `.csproj` beside them was generated by go2cs.
Nobody edited those files by hand. They are TypeScript's code, changed by translation from Go to C#.

Each converted file records the Go source it came from in a `GoPositionMap` attribute, which go2cs uses for
Go-style stack traces. go2cs writes it in module-path form (for example `github.com/microsoft/TypeScript/tsc@/internal/…`),
so no local path appears in them and none was rewritten.

## Changed: one line of TypeScript's `go.mod`, for the conversion only

TypeScript depends on `github.com/zeebo/xxh3` v1.1.0, which reads Go string and slice headers through `unsafe`. go2cs
cannot convert that today. The go2cs project keeps a fork of xxh3 v1.1.0 with every use of `unsafe` removed, which
computes the same hashes bit for bit (its `FORK.md` gives the proof). The conversion used it through one `replace`
directive added to TypeScript's `tsc/go.mod`:

```
replace github.com/zeebo/xxh3 => <go2cs>/src/forks/github.com/zeebo/xxh3@v1.1.0
```

`go mod tidy` then removed one `go.mod` line, `github.com/klauspost/cpuid/v2 v2.2.10 // indirect`, because only xxh3
needed that module, and four `go.sum` lines: cpuid's two and xxh3's two (a local replacement has no checksum). No `.go` file of TypeScript was changed. The native Go side of every comparison
was built from the unmodified `go.mod`. A planned go2cs change (views of string and slice headers over managed memory)
will remove the need for the fork.

So `pkg/github.com/zeebo/xxh3/` is the translation of the fork, not of upstream xxh3. Its BSD-2-Clause `LICENSE` is
verbatim, and its `FORK.md` states what the fork changed.

## Not included

Only the packages that the four demos need are here: the union of the dependency closures of `cmd/parsedemo`,
`cmd/checkdemo`, `cmd/emitdemo` and `cmd/mfdemo`. The rest of TypeScript, including its language service, language
server and command-line compiler, is not included.

## Added: not part of TypeScript

| Path | What it is |
|:--|:--|
| `go/cmd/parsedemo/main.go` | The demo, in Go. It parses `.ts` files and prints their parse diagnostics and syntax-node dump. It was added beside TypeScript's packages only so it could import them. |
| `src/github.com/microsoft/TypeScript/tsc/cmd/parsedemo/` | The demo, converted to C# by go2cs. |
| `go/cmd/checkdemo/main.go`, `src/github.com/microsoft/TypeScript/tsc/cmd/checkdemo/` | The type-check demo, in Go and converted. It type-checks each file in its own in-memory program and prints its diagnostics. |
| `go/cmd/emitdemo/main.go`, `src/github.com/microsoft/TypeScript/tsc/cmd/emitdemo/` | The emit demo, in Go and converted. It compiles each file in its own in-memory program and prints every output file. |
| `go/cmd/mfdemo/main.go`, `src/github.com/microsoft/TypeScript/tsc/cmd/mfdemo/` | The multi-file demo, in Go and converted. It compiles a `tsconfig.json` project in memory and prints every diagnostic and output file. |
| `go/cmd/parsecorpus-extract/main.go` | The corpus extractor, in Go. It runs natively only, and its C# is not included. |

## Third-party modules under `pkg/`

Each module under `pkg/` is a go2cs translation of a Go module that the four demos import. It was changed the
same way: translated from Go to C#. Its license files sit at the module's root, verbatim from the module.

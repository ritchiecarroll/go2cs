## About spf13/pflag

[spf13/pflag](https://github.com/spf13/pflag) replaces Go's standard flag package with command-line parsing in the POSIX and GNU style: long options take two dashes, one-letter shorthands take one, and shorthands can be combined. A program usually moves to it by changing one import, and it is the flag library Cobra is built on.

## About google/uuid

[google/uuid](https://github.com/google/uuid) is Google's Go package for creating, parsing and formatting universally unique identifiers. It makes random version 4 UUIDs, time-ordered version 6 and version 7 UUIDs, name-based UUIDs hashed with MD5 or SHA-1, and the older time-based and DCE Security forms, and it reads the usual text forms back. A UUID is a 16-byte array, so two values compare with == and one can serve as a map key.

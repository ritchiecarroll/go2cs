## About spf13/cobra

[spf13/cobra](https://github.com/spf13/cobra) is a library for building command-line applications in Go. A program is a tree of commands, each with its own flags (parsed by pflag), arguments and help text, and Cobra writes the help and usage output, suggests a command when one is mistyped, and generates shell completion scripts for bash, zsh, fish and PowerShell.

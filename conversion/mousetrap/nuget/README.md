## About inconshreveable/mousetrap

[inconshreveable/mousetrap](https://github.com/inconshreveable/mousetrap) answers one question for a command-line program on Windows: was it started by double-clicking it in File Explorer rather than from a console? A tool can use the answer to show instructions and wait, instead of printing its help into a window that closes before anyone reads it. On every other operating system the answer is always no.

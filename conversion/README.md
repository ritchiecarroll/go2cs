## What is here

| Path | What it is |
|:--|:--|
| `mousetrap/*.cs`, `mousetrap/github.com.inconshreveable.mousetrap.csproj` | the module's root package, converted for linux/amd64: C# generated by go2cs from the Go source. Do not edit it: change the Go module and convert again. |
| `mousetrap/Directory.Build.targets` | written by the nugetgo pack: the assembly's copyright names the upstream holder |
| `mousetrap/nuget/README.md` | the package's README on nuget.org: its About section is written by hand, and the nugetgo pack rewrites only its generated block |
| `Directory.Build.props`, `Directory.Build.targets` | the build settings go2cs generated; `GoStdLibVersion` is set here |
| `LICENSE` | the upstream license, verbatim (Apache 2.0) |
| `VALIDATION.md` | the behavioral proof the NuGet package ships, one row per runtime, byte for byte as packed |

The module sits one directory below the root build files on purpose: `mousetrap/Directory.Build.targets` imports the
nearest `Directory.Build.targets` above its own directory, which is the root one.

The package's Windows and macOS assemblies are converted from the same source with `-platforms windows/amd64` and
`-platforms darwin/amd64`; the Windows conversion carries `trap_windows.go` where this one carries `trap_others.go`.

## Building

```
cd mousetrap
dotnet build github.com.inconshreveable.mousetrap.csproj -c Release -p:GoStdLibVersion=1.26.10.1
```

The restore takes the `go.*` packages from nuget.org. `-p:GoStdLibVersion=1.26.10.1` pins the go2cs standard-library
release the package was built against; without it the build takes the newest `1.26.*`.

## Provenance

Converted with `go2cs -recurse=nuget -platforms linux/amd64` at go2cs commit `430f3ad68a`, which carries the go.* 1.26.10.1
release's runtime and source generators unchanged, plus the nugetgo rebuild tools. mousetrap has no Go tests; its
proof is one behavior row per shipped runtime: the module's sample program run with `go run` and, converted against
the package, with `dotnet`, on a hosted runner of that operating system, with byte-identical output. The package ships
those rows as `VALIDATION.md`.

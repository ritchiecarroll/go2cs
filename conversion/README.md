## Building

```
cd src/github.com/itchyny/gojq
dotnet build github.com.itchyny.gojq.csproj -c Release -p:GoStdLibVersion=1.26.10.3
```

The restore takes the `go.*` packages from nuget.org and builds timefmt-go from `pkg/`. `-p:GoStdLibVersion=1.26.10.3`
pins the go2cs standard-library release the package was built against; without it the build takes the newest `1.26.*`.

## NuGet

from this repository's tag `nuget-1.10.2`. A rebuild of the same Go version adds a fourth, revision part: `1.10.2.N`,
where N counts up from 1. The package holds one assembly per operating system, the module's root package: its Windows

`src/` and `pkg/` keep the paths the conversion gave them.

## Building

```
cd src/github.com/spf13/cobra
dotnet build github.com.spf13.cobra.csproj -c Release -p:GoStdLibVersion=1.26.10.1
```

The restore takes the `go.*` packages from nuget.org and builds pflag from `pkg/`. `-p:GoStdLibVersion=1.26.10.1`
pins the go2cs standard-library release the package was built against; without it the build takes the newest `1.26.*`.

## Provenance

Converted with `go2cs -recurse=nuget -platforms linux/amd64` at go2cs commit `ee99292ba8`, which carries the go.* 1.26.10.1
release's runtime and source generators unchanged, plus the nugetgo rebuild tools. The module's Go tests were converted
and compared at the same commit, run without root privileges: 405 matched, 0 disclosed in the root package. `doc`
matched 19 of 19 and is not in the package. The package ships that report as `VALIDATION.md`.

# hashset-cs

The C# conversion of the Go module [`github.com/ritchiecarroll/hashset`](https://github.com/ritchiecarroll/hashset)
v1.0.0, made by [go2cs](https://github.com/ritchiecarroll/go2cs). It is published on NuGet as
[`nugetgo.github.com.ritchiecarroll.hashset`](https://www.nuget.org/packages/nugetgo.github.com.ritchiecarroll.hashset);
this repository's tag `nuget-1.0.0.3` is the source of version 1.0.0.3.

go2cs C# conversion of github.com/ritchiecarroll/hashset v1.0.0, published by its author, built on the Go 1.26.10
standard library; not affiliated with or endorsed by the Go project. Security: the Go standard library this package is
built on includes no Go security fixes released after Go 1.26.10; review before any production use.

## Building

```
dotnet build -c Release -p:GoStdLibVersion=1.26.10.1
```

The restore takes `go.lib` and `go.gen` from nuget.org. `-p:GoStdLibVersion=1.26.10.1` pins the go2cs standard-library
release the package was built against; without it the build takes the newest `1.26.*`.

## Provenance

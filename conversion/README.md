## What is here

| Path | What it is |
|:--|:--|
| `uuid/*.cs` | C# generated by go2cs from the Go source. Do not edit them: change the Go module and convert again. |
| `uuid/github.com.google.uuid.csproj`, `.slnx` | the project go2cs generated |
| `uuid/Directory.Build.targets` | written by the nugetgo pack: the assembly's copyright names the upstream holder |
| `Directory.Build.props`, `Directory.Build.targets` | the build settings go2cs generated; `GoStdLibVersion` is set here |
| `LICENSE` | the upstream license, verbatim (BSD 3-Clause) |

The project sits one directory below the root build files on purpose: `uuid/Directory.Build.targets` imports the
nearest `Directory.Build.targets` above its own directory, which is the root one.

## Building

```
cd uuid
dotnet build -c Release -p:GoStdLibVersion=1.24.13.5
```

The restore takes the `go.*` packages from nuget.org. `-p:GoStdLibVersion=1.24.13.5` pins the go2cs standard-library
release the package was built against; without it the build takes the newest `1.24.13.*`.

## Provenance

Converted with `go2cs -recurse=nuget -platforms linux/amd64` at go2cs commit `7888e4e72f`, which is the go.*
1.24.13.5 release with the nugetgo pack tools merged. The module's Go tests were converted and compared at the same
commit: 54 matched, 0 disclosed. The package ships that report as `VALIDATION.md`.

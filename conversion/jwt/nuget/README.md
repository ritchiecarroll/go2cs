## About golang-jwt/jwt

[golang-jwt/jwt](https://github.com/golang-jwt/jwt) is a widely used Go implementation of JSON Web Tokens. It builds, signs, parses and verifies tokens with HMAC, RSA, RSA-PSS, ECDSA and Ed25519 signing methods, checks the standard registered claims such as expiry, not-before, issuer and audience, and lets an application add claims of its own. Its request package reads a token from an HTTP request.

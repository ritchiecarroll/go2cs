## Disclosed divergences

A disclosed divergence is a specific Go assertion this conversion does not satisfy — not
a skipped test and not a tolerance. Each one is pinned by exact failure signature in the package's
hand-owned [`go2cs_test_disclosures.json`](https://github.com/ritchiecarroll/go2cs/blob/master/src/core/database/sql/go2cs_test_disclosures.json);
a disclosed test that fails any *other* way is still a hard mismatch.

The **Class** column says which kind each one is: a `deferred` entry is an assertion the managed
CLR *can* meet, pinned against the named plan that will retire it; every other class is one it
*provably cannot* satisfy.

| Test | Class | Pinned reason |
|:--|:--|:--|
| `TestGrabConnAllocs` | `alloc-count-semantics` | Want-zero AllocsPerRun assert on Conn.grabConn: Go allocates nothing. The converted path allocates 96 bytes per run (96,000 bytes over 1,000 runs on windows and linux, at go1.24.13 and go1.26.10) and golib's counter charges none of it, so the 96 the test prints (`Conn.grabConn allocated 96 objects; want 0`) is a byte figure and no object count exists to compare with the want. What remains is outside the counter. |
| `TestRawBytesAllocs` | `deferred` | Want-zero AllocsPerRun assert (the test fails above 0.5) over fourteen convertAssign cases into a pre-sized RawBytes: Go's escape analysis keeps the temporaries off the heap. The converted run counts 28 objects per run at go1.24.13, two per call over the fourteen cases, and 11 per run at go1.26.10 on windows and linux (identical test body). Boxing into `any` is not counted; which objects are counted is not yet attributed. Candidate sites are strconv formatBits' local array (strconv/itoa.cs:89), which six of the cases reach through asBytes, and the reflect path's Value construction on every call. |

## 3. The population of record: 230 → 242

`docs/phase4/data/population-go1.26.9.txt`, generated by `go run ./internal/genpopulation -goroot <go1.26.9>` (axis
windows/amd64, tags `purego,math_big_pure_go`): **362 listed, 246 with a surviving test file, 242 declaring a test**
(the same four empty ones as at 1.25.14). Against population-go1.24.13.txt: **17 added, 5 removed,
230 + 17 − 5 = 242.**

Added rows: `crypto/fips140`, `crypto/hpke`, `crypto/internal/fips140/mldsa`, `crypto/internal/fips140/subtle`,
`crypto/internal/fips140cache`, `crypto/internal/fips140only`, `internal/runtime/cgroup`, `internal/runtime/gc/scan`,
`internal/runtime/wasitest`, `internal/strconv`, `internal/syscall/unix`, `internal/trace/internal/tracev1`,
`internal/trace/testtrace`, `internal/trace/tracev2`, `math/big/internal/asmgen`, `testing/cryptotest`,
`testing/synctest`.
Removed rows: `crypto/internal/hpke`, `go/ast/internal/tests`, `internal/itoa`, `internal/trace/internal/oldtrace`,
`runtime/internal/wasitest`.

`internal/syscall/unix` is not a new package: its new `fchmodat_test.go` and `kernel_version_ge_test.go` are the
first of its test files to survive the windows axis.

**The exclusions, read against the new population.** `Get-HopPopulationRows` builds 238 rows (242 less the four
ledger exclusions still in the population). The fifth, `runtime/internal/wasitest` (E1), is gone, and its tests are
`internal/runtime/wasitest`'s (§4). E1's reasons hold there file for file at 1.26.9: `nonblock_test.go` still carries
`//go:build ... && !windows`, `host_test.go` declares no test, and `TestTCPEcho` still skips unless the target is
`wasip1/wasm`. **For COORD's ruling:** re-rule E1 onto `internal/runtime/wasitest`; until then it is an ordinary
row that would read as all-skip.

**RULED 2026-10-14 (COORD):** E1 is re-ruled onto the successor `internal/runtime/wasitest`; the reasons above hold
file for file at 1.26.9, so it is not an all-skip row.

## 4. Relocations by body: `docs/phase4/data/relocations-go1.26.9.tsv`

Every test function of the 17 added and 5 removed rows was matched against every std test of the other release
(the method and every score are in the file's header). **Five arcs:**

| source | target | evidence |
|:--|:--|:--|
| `runtime/internal/wasitest` | `internal/runtime/wasitest` | both tests 0.98, both files 0.99 |
| `internal/trace/internal/oldtrace` | `internal/trace/internal/tracev1` | 3 of 3 tests at 1.00 |
| `go/ast/internal/tests` | `go/ast` | its one test, 1.00 |
| `strconv` | `internal/strconv` | PARTIAL: 37 functions left `strconv`, 24 more are in both |
| `runtime` | `internal/strconv` | PARTIAL: `TestAtoi` (0.84); `TestAtoi32` left with no successor |

**Two by-name relocations the RECON listed do not hold by body:**
- `crypto/internal/hpke` → `crypto/hpke`. Its test scores 0.17 at best, and its vectors were replaced (6 entries in
  the old schema, 24 in RFC 9180's). A true removal and a new row.
- `internal/itoa` → `internal/strconv`. Same-named tests score 0.17 and 0.40; internal/strconv's itoa tests come
  from `strconv` (1.00). A true removal.

A partial arc annotates the target with the source's whole banked count: `internal/strconv` reads
"receives `runtime (10819)`" though one test moved, as ruled for the same shape at 1.25.14 (kept as provenance).

**AMENDED 2026-10-15 (COORD ruling on H3 route 2, the i9):** the `runtime` → `internal/strconv` arc is DROPPED, and
its row is removed from the TSV, which now holds four arcs. The i9 read the bodies: internal/strconv's `TestAtoi` uses
strconv's `parseInt32Tests`/`parseInt64Tests` and the error-returning `Atoi`. runtime's used `atoi32tests`/`atoi64tests`
and `runtime.Atoi`'s ok bool, and those tables exist nowhere at go1.26.9 (checked: only 1.24.13's
`runtime/string_test.go` holds them). The 0.84 above was the shared switch/range/Errorf skeleton; the exact-body ratios
are runtime 0.43 and strconv 0.64. runtime's `TestAtoi` and `TestAtoi32` are recorded as DELETED at 1.26, and
`internal/strconv` receives nothing from `runtime`. The population (242) and the other four arcs agree byte for byte.

## 7. New constructs, each with its probe (lesson 54)

Censused over std (cmd and testdata excluded) at both releases by one parser-based scan, then diffed.

**`//go:embed`: 20 directives in 5 importing files → 27 in 10.** New in a default-set row:

| site | form | probe |
|:--|:--|:--|
| `internal/strconv/fp_test.go`: `testdata/testfp.txt`, `testdata/atof1k.txt`, `testdata/ftoa1k.txt` | blank import, `string` | **owed**: no behavioral test imports `embed` |
| `crypto/internal/fips140test/acvp_fips140v1.26_test.go`: `acvp_capabilities_fips140v1.26.json` | blank import, `[]byte` | **owed**, same |
| `crypto/internal/fips140test/acvp_test.go`: `acvp_capabilities.entropy.json` (was `acvp_capabilities.json`) | `[]byte` | **owed**, same |

Outside the default set: `acvp_fips140v1.0_test.go` (tag `fips140v1.0`), `encoding/json/internal/jsontest/testdata.go`
(named import, `embed.FS` over a glob; jsonv2), `net/url/gen_encoding_table.go` (`//go:build ignore`). The converter
resolves patterns itself and has unit arms for the blank and named forms (`embedDirective_test.go`), but no
behavioral probe runs an embedded payload. **Proposed:** one behavioral probe, `EmbedDirectiveForms`, covering a
blank-import `string`, a blank-import `[]byte` and a named-import `embed.FS` over a glob, each read back at run time.

**Linker-synthesized `//go:linkname` targets: unchanged.** The one `go:`-symbol target is
`crypto/internal/fips140/check.Linkinfo` → `go:fipsinfo` at both releases. The scan also lists linknames whose target
has no Go or assembly definition in std; those changed only by naming: the four `reflect.mapiter*` shims moved from
`map_swiss.go`/`map_noswiss.go` to `runtime/linkname_shim.go`, and the `maps.keys`/`maps.values` pushes are gone.
**One new push into a test package:** `runtime/mcleanup.go` →
`sync_test.runtime_blockUntilEmptyCleanupQueue`, for the linkname push registry's H4 delta.

**New syntax** (plan §3.2):

| form | std uses | probe |
|:--|:--|:--|
| `new(expr)` | 1: `runtime/secret/secret_test.go:58`, `new(secretType(secretValue))`, outside the default set (runtimesecret) | **owed at H4** with the feature (the nugetgo axis needs it for modules declaring `go 1.26`) |
| generic self-reference in a type-parameter list | 0 | **owed at H4** with the feature |
| generic type aliases (graduated at 1.24) | as banked | `GenericTypeAlias`, `GenericTypeAliasBystander`, `GenericTypeAliasLib` |

The `new(expr)` count covers operands that are expressions by syntax (calls, conversions, literals, operators).
A bare identifier naming a variable needs type information to tell from a type; that heuristic misfires on
type-parameter names and is not counted.

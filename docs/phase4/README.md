# docs/phase4: engineering records

This folder holds go2cs's internal engineering records: design notes, measurements, censuses,
rehearsals and the findings ledger written while the converter was built and validated. They are
point-in-time records, kept for provenance. They are **not** user documentation, and none of them is
published on go2cs.net.

For using go2cs, start at the [project README](../README.md) and the [documentation index](../README.md).

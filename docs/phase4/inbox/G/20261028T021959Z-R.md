GOLIB (additive; the OLD corpus never names it): a non-generic `public static class slice` beside slice<T>, with
  `public static slice<T> Create<T>(ReadOnlySpan<T> items)` that ALWAYS allocates `new T[items.Length]` and copies, so
  `[]` is NON-NIL with len == cap == 0 (Go's `[]T{}`), every evaluation gets a fresh backing array (Go's aliasing), and
  len == cap; plus `[CollectionBuilder(typeof(slice), nameof(slice.Create))]` on slice<T>. C# calls the builder for
  `[]` too (measured on a stand-in type: one Create call, non-nil, len 0), so empty needs no special case.
THE RULE: the converter emits `[e1, …]` for an UNKEYED single-level `[]T{…}` literal (T's slice type UNNAMED) only when
  the literal's PARENT gives it a target whose C# type is exactly `slice<T>` AND that target is decided before overload
  resolution. The parent marks the literal, as markStringFieldLits / markEmptyInterfaceElems do; convCompositeLitAs
  reads the mark, so an unmarked literal keeps today's `new T[]{…}.slice()` byte for byte. Eligible parents:
  1. a typed local: `x := []T{…}` / `var x []T = …` -> `slice<T> x = […];` (owner §6.3), single-name declarations only;
  2. an assignment to an existing variable, field or element whose Go type is the same unnamed `[]T`;
  3. a `return` operand whose result type is the same `[]T` (inside a lambda too: its delegate type is stated);
  4. a struct-literal field (`new box(data: […])`, the keyed ctor's named argument), a map-literal value
     (`["k"] = […]`, the indexer) and an element of an ELIGIBLE outer literal (nesting composes top-down);
  5. a call argument whose callee is a converted, NON-generic Go function, method, interface method or func value
     whose parameter at that position is `[]T` (not variadic, not a `...` spread).
  EXCLUDED (today's form kept), each a property the converter already reads from go/types:
  a. golib builtins and every call into a hand-owned package or a manualConversionFuncs entry (C# overload sets);
  b. a generic callee whose type arguments are INFERRED: C# DOES infer T through a builder type (measured: it
     compiles), but from the ELEMENT expressions, so `F([]int{1, 2})` would bind T = System.Int32 where Go binds
     int (nint); an explicit instantiation `F[int](…)` is eligible;
  c. a callee go2cs-gen overloads at that position: an sstring twin, and any receiver-overloaded method whose
     slice parameter differs between overloads (in practice none; kept as a rule, not a census);
  d. any `any` or interface slot (`fmt.Println([]int{1})`), a conversion `T(x)`, `&[]T{…}`, a literal used as a
     receiver, index or slice operand, a range operand, a `len`/`cap`/`append` operand;
  e. keyed or sparse literals (`[]T{5: x}`), fixed arrays (`[N]T`, `[...]T`), and a NAMED slice type anywhere.

# named-pipe hang: probe for the i9 + static read (CancelIoEx has no record for pipe reads)
from: P2 · to: COORD · 2026-10-17T15:39:40Z

P2 -> COORD: os (2) named-pipe hang. I cannot run windows here, so this is a probe for the i9 plus a
static read, not a measurement. Pushing now: claude/p2-pipe-deadline d501c4df79 (on 3bdac60827),
docs/phase4/probes/p2-named-pipe-deadline/ (README + main.go, windows only, vetted GOOS=windows).

The probe builds the test's exact pair (CreateNamedPipe overlapped + os.NewFile; os.OpenFile with
O_FILE_FLAG_OVERLAPPED) and runs three steps, each under its own 10 s guard so a hang is named:
  A. read deadline 50 ms, no writer         Go: i/o timeout ~50 ms   hang = timed-out read never cancelled
  B. one 5-byte write, one read             Go: n=5 at once          hang = completion never reaches the poller (port bind)
  C. Close under a pending read, no deadline Go: file already closed  hang = Close's CancelIoEx(h, nil) not waking it
Run: go2cs <probe dir> <out dir>, build, run; `go run .` as the oracle on the same box.

STATIC READ behind A (my leading candidate, unmeasured):
- syscall.readFile/writeFile are CONVERTED (zsyscall_windows.cs:1393): the OVERLAPPED crosses as
  (uintptr)&o.o and no GoAsyncIO operation record is made for it.
- The hand-owned CancelIoEx (zsyscall_windows_wsa_impl.cs:668) cancels a non-nil overlapped ONLY via
  its GoAsyncIO record and answers ERROR_NOT_FOUND without one. cancelIO reads that as "completed" and
  calls runtime_pollWaitCanceled, which waits for a completion; a pipe read with no data never posts one.
- The 5 s `max` timer not ending the subtest fits that: t.Fatalf runs the deferred Close, and Close then
  waits on the read that still holds the fd.
- Separately: &o.o is an interior field of the pooled, reference-bearing `operation`, so the address the
  kernel holds during the I/O is not pinned. Noted, not chased.
If A hangs and B passes, the fix I would propose: CancelIoEx with no record cancels by the address the
submit itself passed ((uintptr)Ꮡo, the raw interior address), which is what Go does. Red-first by the
subtest on the i9; I will not write it until A's reading is in.

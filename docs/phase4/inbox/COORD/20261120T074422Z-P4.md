- Symptom: the build fails against the published go.* packages with CS0426 on a Δ-prefixed name (reflect_package.ΔKind); the conversion warns nothing and exits 0.
- Cause: under -recurse=nuget the converter looks for a local root (-go2cspath, else GO2CSPATH, else ~/go2cs, %USERPROFILE%\go2cs on Windows) and reads each imported package's names from it ahead of its embedded metadata; an older root supplies that release's names. - Workaround: unset GO2CSPATH and pass -go2cspath an empty folder, or move the old ~/go2cs aside. Measured on windows-amd64 and linux-x64.

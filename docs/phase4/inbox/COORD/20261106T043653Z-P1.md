Reading the path before measuring: the first structural assert runs Implements -> StructurallyImplements ->
GetGoMethodSetCandidates(element, isPointer). The first call runs golib's extension scan; under AOT there is no
raw metadata, so the TypeDef walk falls back to GetTypes() on every assembly. Then, PER (element, pointer) KEY,
the filter walks EVERY extension method and, for a value key, calls GetCustomAttribute<GoRecv> on each before it
checks whether the receiver even matches. Under AOT each attribute read decodes NativeFormat metadata.

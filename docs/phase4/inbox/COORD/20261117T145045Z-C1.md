## What separates the rules: one banked project
internal/syscall/windows/registry is banked green on windows (6 verdicts). Its test calls `k.Stat()`, and it
references os but not io/fs. `os.File.Stat` is emitted as `(FileInfo, error) Stat(this ж<File>)`, where FileInfo is
io/fs's type (os/windows/package_info.cs:34). So a same-named extension candidate whose return names an unreferenced
assembly did NOT need it when its receiver is `this ж<T>`. t2b's candidate is `this ref Backup`, and there it did. The
rule that fits t2b, registry and all 242 projects: C# needs the signature assemblies of same-named candidates emitted
as `this ref T`. This is a hypothesis fitted to 1 red and 243 greens, not read from Roslyn's source. The red's build
arm is what tests it again.

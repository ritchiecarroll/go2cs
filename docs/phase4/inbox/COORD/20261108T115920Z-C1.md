## One conflict with the ruled =exp form (I'm raising it, not picking)

annotate_darwin.py, the tool that writes the darwin: segments, reads every evidence row with int(divergent) and
int(new) in reading(), outside any try. An `=exp` cell raises ValueError there, so the annotation would stop at the
first PASS row. Three ways out:
- (1) the annotation seat resolves =exp to the tip's expectation numbers before running, with the README as the
  provenance;
- (2) the tool learns =exp, meaning keep the existing segment;
- (3) I write the expectation numbers and add a column `cells=implied`.

I write `=exp` as ruled unless you say otherwise. The README on the ref states each column's source.

# OQ-L3(b) per-test watchdog: SIZE + SKETCH (design only, no cut)
from: C1 · to: COORD · 2026-10-17. Read at hop tip 5adb2dfb58 (src/core/testing).

WHERE A HANG BLOCKS TODAY:
- TestRunner.RunAll runs each top-level test, then WaitForSerialBoundary(execution) waits on
  Task.WhenAny(Completion, ParallelReached) with NO bound.
- Only TestHost's run.Wait(options.Timeout), the package deadline, ends it: one "timeout" event, every later test
  unmeasured.
- Goroutine threads are IsBackground (golib Goroutine.cs:1070), so an abandoned thread cannot hold the process at exit.

SKETCH:
1. Host flag --test-deadline d (0 = off, today's behavior). The -tests pipeline passes it; the converter flag defaults
   it to a fraction of -test-timeout (proposal: 15 m, below the 2 h row deadline and above the longest banked solo test).
2. WaitForSerialBoundary becomes a bounded wait. On expiry the runner ABANDONS the execution:
   - it reports `fail` for the test and its in-flight subtests;
   - the output is synthesized and names the test, the deadline, and that its goroutines keep running;
   - it counts the failure, restores the descriptor limit, and starts the next test.
   A parallel test is bounded the same way at its own Wait after ReleaseParallel.
3. The abandoned thread cannot be stopped (the CLR has no thread abort). Every LATER event carries an
   `afterAbandoned: <name>` tag, so a cascade (a held lock or a shared global) reads as one, and the comparison
   prints it.
4. Converter side: the comparison maps the watchdog's fail to its own label (`abandoned`, not `fail`), so it is never
   mistaken for a converted-code failure. A disclosure can pin its synthesized text with an ordinary signature,
   which is ⟨OQ-L3⟩(b)'s point: the row FAILS, visibly, with text.
5. HANG-class host-fatal entries stay valid; they withdraw the test from both sides. The watchdog is the backstop for
   hangs nobody has found yet. It does not replace an entry.

POPULATION IT WOULD HAVE SAVED: 3 rows this hop by your count (synctest, runtime x2). 4 HANG-class host-fatal
entries exist today (all runtime: TestPanicSystemstack, TestProfBufWakeup, TestEmptySlice, TestEmptyString),
plus 9 crash-class (unaffected: a crash already ends the run with a marker).

SIZE (estimate, not measured):
- Host: TestRunner + TestExecution + TestReporter, about 150-200 lines, with an abandon path that is safe against
  the test completing during the abandon (one CAS on the execution state).
- Converter: flag plumbing plus the comparison label, about 40 lines. Tests: a hand-owned testing self-test (a test
  that blocks forever beside one that passes after it), a GolibTests arm for the cascade tag, and a converter test
  for the label.
- About one seat, G reviews. The risk is cascade: a hung test can hold a runtime lock that the next test needs.
  The tag makes that visible; it does not prevent it.

OPEN, for a ruling before any cut:
- (a) the default deadline (15 m proposed);
- (b) whether `abandoned` counts in the row's denominator as a fail (my recommendation: yes, a visible fail);
- (c) whether the oracle side gets the same bound (Go has no per-test deadline; my recommendation: no, so Go's
  verdict stays Go's).

# C2 stack-append: the own-body rule drops 45 closure-local sites where Go uses the buffer (ruling asked)
from: C2 · to: COORD · 2026-10-20T00:03:11Z

C2 -> COORD (for G): STACK-APPEND, ONE POINT BEFORE THE CONVERTER CUT (cut on 874374df34 as claude/c2-stack-append;
golib, GO2CS0007 and the red fixture are under way and do not depend on this).

The own-body rule as worded loses Go parity at every site it drops.
- I classified all 45 dropped site-instances (std and std tests, every target). Every one is CLOSURE-LOCAL: the
  appended variable is declared inside the same FuncLit that appends to it, for example
  `t.Run(..., func(t *testing.T) { var got []T; got = append(got, v) ... })`.
- None is a captured outer variable. A captured outer variable escapes or is address-taken, so -m never hints it.
- For a closure-local variable, Go keeps the buffer and the `used` flag in the CLOSURE's frame, per call. Go gives
  `cap(got)` 4 there. Without a hint, the C# gives 1.

PROPOSED, to keep G's guard intact and Go's numbers:
- The buffer local is declared at the entry of the innermost function containing the append: the FuncDecl body,
  or the FuncLit's lambda body.
- The hint is given only when the appended variable is declared in that same function, which is already true of
  all 45.
- A C# lambda invocation is a fresh frame exactly as a Go closure call is, so `xᴷ` declared in the lambda body
  resets per call, as Go's does.
- GO2CS0007 already admits a local "declared in the SAME method or lambda as the call and not captured". The worst
  case it guards (an outer xᴷ snapshotted into a lambda's xᴷʗ1) cannot arise, because no hint ever crosses a
  FuncLit boundary.
- Prediction under this rule: back to the original numbers. Std 179 sites / 116 .cs, std tests 177 / 109,
  behavioral 42 / 24, 140 position maps.
- The red fixture gains a closure arm: a closure-local append prints Go's 4, which no hint would print as 1.
Absent a ruling, I build the converter with G's literal rule (own body only), so nothing is blocked. I name the 45
sites in the disclosure as Go-parity misses.

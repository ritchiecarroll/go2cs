 conversion "emits for exactly one target", CommandLine.md). The go.* packages ship runtimes/<rid>/lib flavours
 (push-nuget.ps1). So: packed on linux, a windows consumer silently loses the mousetrap check; packed on windows,
 a linux consumer runs windows mousetrap against linux go.syscall, which has no CreateToolhelp32Snapshot (reasoned,
 not measured: a MissingMethod/TypeLoad on cobra's Execute path). PROPOSE P1: a per-flavour pack (convert once per
 GOOS, merge runtimes/<rid>/lib/<tfm>, keep lib/ as the compile asset since the surface is identical, write the
 flavoured `name@goos` metadata sections the self-description format ALREADY reads). Tools only: no converter, no
 go.* change, no release forced. Only mousetrap and cobra need it; pflag/blackfriday/md2man/yaml have no GOOS files.

## Findings (not fixed here)
- F1 CONSTANT re-panics: residual, needs the converter. Go dedups a constant's read-only data, so
  `defer func(){ recover(); panic(1000) }(); panic(1000)` prints [recovered, repanicked]. Measured the same for -1,
  "x" and pair{1,2}. A COMPUTED 1000 does not (measured: dynlarge, dynstr, pairdyn).
  The emission boxes `panic((nint)1000)` and `panic(new pair(1, 2))` afresh at each site, so the runtime cannot tell a
  constant from a computed value. Only string LITERALS are caught, by interning. A named string const
  (`static readonly @string`) is boxed fresh too and is NOT caught.
  Converter shape, if wanted: box a constant panic argument once per value, as Go's linker dedups it.

  `true` (measured; that arm pins only the chain structure). Go 1.26 prints floats as `1.5`/`0.25`, complex as
  `(1+2i)`, a named basic type as `main.myInt(7)`, and indents a multi-line string (printindented). golib's text for

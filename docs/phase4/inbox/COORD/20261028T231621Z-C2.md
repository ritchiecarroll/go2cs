**Root cause.** KindOf maps every CLR primitive to its Go kind except System.Char, which fell through to Struct.
Struct is the one kind whose walks descend into a type's fields, and a char's one field is itself a char
(m_value). So IsComparable -> StructFieldsComparable never ends: %v of a boxed char overflows at 58,048 frames.
%T alone does not overflow, but it printed `func(int32) Char`. P2 hit the overflow on the char lambdas their r2
emitted. The code comment and the runbook both rested termination on CS0523, and the CLR's primitives are the
exception to that rule.

**Fix.** KindOf(char) = Uint16 and GoTypeName(char) = "uint16": a char is a UTF-16 code unit. Measured:
- %T of Func<int, char> prints `func(int32) uint16`.
- %v %d %x %T of 'x' print `120 120 78 uint16`.
- reflect Kind uint16, Uint 120, Comparable true; DeepEqual true; usable as a map key.
- Residual: a reflect write into a char-typed slot builds a ushort. No Go program has such a slot.

## 0. Row 8, measured (owed today): System names the emitter writes unqualified, vs package-level Go names

**Surface.** Every converted project imports `System` and `System.Numerics` (csproj-template.xml:141-142). I read their public types from the net10.0 reference pack: 273 names, 229 in System and 44 in System.Numerics. A package's own nested type or member beats a namespace import, so the question is which of these the EMITTER spells unqualified.

**Unqualified and non-generic** (scan of converter string literals and generator templates, each site read):
- `Exception`: the GoFrame catch, goFrameOperations.go:170. A user nested `Exception` is CS0155, loud (probe).
- `Action`: an IIFE over a void literal, iifeOperations.go:260. A user `Action` delegate with the same signature compiles and stands in harmlessly (probe). A different signature is loud.
- `Delegate`: casts, funcWordOperations.go:474 and :484. Loud by C# rules.
- `ICloneable`: `object ICloneable.Clone()`, StructTypeTemplate.cs:370. Loud: an explicit implementation of a non-interface is an error.

**Occurrences:** package-level Go `Action`, `Exception`, `Delegate`, `ICloneable`: **0** in every corpus.

**Saved by arity or position:**
- `Func<…>`, `Action<…>`, `Span<…>`, `ReadOnlySpan<…>` are always written generic. They meet the package-level Go names `Func` (debug/gosym type, internal/abi const, flag func), `Span` (behavioral type) and `Tuple` (go/types) safely, because a type lookup takes name and arity, and skips functions and constants.

**Status:** latent and loud. No silent case has occurrences.

**One existing hand list in this class:** `systemCollidingTypeNames` (visitImportSpec.go:50, 51 names). It roots a package's own type inside assembly-level attributes, against CS0104. It is curated, and the full surface has 273 names. It folds into the manifest below.

## 2. Format and placement: `src/go2cs/reservedSurface.txt`
- It is embedded with `//go:embed`, as fieldAccessCollisions.txt is, so route #5's derived embed set covers it.
- go2cs-gen embeds the same file as a resource, as it already embeds fieldAccessCollisions.txt.
- **Layout:** UTF-8, LF, sorted. A header line holds the render's inputs: LangVersion from the template, the reference-pack major, and golib's assembly version.
- **Line format:**
  ```
  <section>\t<name>\t<arity>\t<visibility>\t<rule>\t<source>
  golib-static	len	*	public	qualify	go.builtin
  golib-static	ZeroIsDefault	0	internal(go.runtime,go.unsafe)	qualify	go.builtin
  box-member	NilBox	0	public-static	rename-Δ	go.ж`1
  template-member	Slice	0	public	claim	slice
  keyword	record	-	-	rename-Δ-type-decl	roslyn:contextual
  system-type	Exception	0	public	root-in-attribute	System
  marker	Ꮡ	-	-	refuse	converter:PointerPrefix
  ```
- **The rule column** is what the converter applies:
  - `escape-@`;
  - `rename-Δ`;
  - `rename-Δ-type-decl` (csReservedTypeNames' rule);
  - `qualify` (golibCall);
  - `claim` (a template emits the member explicitly or under Δ: R7);
  - `refuse` (named diagnostic);
  - `escape-‿` (reserved for a later Δ escape);
  - `root-in-attribute`.
- Derived rows carry their source. A **hand row is allowed** but must say `hand:<reason>`, so nothing hand-kept hides. These are the leftovers of `reserved` such as `type` and `AreEqual`, and the contextual-keyword POSITION classes (§3.3).

### 3.3 Keywords: derived membership, hand-kept position class
- Roslyn says WHICH words are keywords. It does not say where a Go name breaks, so the position class stays a hand table with a reason per row: reserved, type-position, member-start, pattern, accessor, inert.
- The guard is a **completeness test**: a Roslyn keyword with no classification row fails. A Roslyn bump or a LangVersion change in the template then fails until someone classifies the new word.
- That is R6's completeness half. R6 keeps the position FIXES (record/partial, EmbedHop `field`, when/and/or/not).

## 4. Folding the existing lists
- **golibNamespaceNames.go:** becomes a thin Go file whose maps are built at init from the manifest's golib sections, with the SAME variable names. R2 and every current consumer compile unchanged. GolibNamespaceNamesTests is retired once the GenTests render covers it, so there is one renderer.
- **fieldAccessCollisions.txt:** consumers read the box-member section (fieldAccess.go:80 and FieldAccessGenerator.cs:776). The file is deleted.
- **`reserved`, `keywords`, csReservedTypeNames, emitterSpelledTypeNames, systemCollidingTypeNames:** each becomes a view over the manifest, selected by section and rule. What derives nothing stays as a `hand:` row.
- **Bootstrap, stated:** the generator reads box-member to rename template members, and template-member is derived by running the generator. A change to box-member can therefore move template-member, so the test asks for a second regen, which is then stable. Each section is derived from its own source, so no section depends on itself.

## 5. Guards
1. **GenTests (battery and os-matrix):** the render byte-compare, plus the known-members test, plus the keyword completeness test.
2. **`go test ./...`:** a converter-side test.
   - The manifest parses, every section is non-empty, and the header's LangVersion equals csproj-template.xml's.
   - Every non-ASCII rune in symbols.go's constants is in the marker section.
   - This half catches a converter-side marker the moment it is added, without waiting for GenTests.
3. **Positive control at the seat:** delete one row of each section and the test reds naming it; restore and it is byte-identical. Run per section.
- **Platform:** golib's reflected surface must be the same on every OS leg. GolibNamespaceNamesTests already passes on every leg, which says it is. The reference pack's public API is frozen within a .NET major, so a patch roll does not churn the file.

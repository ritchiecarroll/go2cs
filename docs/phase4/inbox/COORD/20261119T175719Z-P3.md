1. methodHolder.go:946 with convSelectorExpr.go:1503. A method expression of a main type without a holder is emitted bare, `((Func<plain, nint>)(Size))`, from wherever it is written. The bare name binds only inside main_package. Three sites where it does not, all valid Go that names `mainᴛplain.Size` and compiles on master:
   a. Inside a KEPT holder. `type words []string; func (w words) len() int { f := plain.Size; return f(plain{1}) }`: words keeps its holder (len), so the cast is emitted in class mainᴛwords. There main_package arrives through `using static`, which never brings an extension method as a method group (the comment at convSelectorExpr.go:1495 says so). CS0103.
   b. Under a local of the method's name. `func main() { Size := plain.Size; ... }` gives `var Size = ((Func<plain, nint>)(Size))`: the local binds first. CS0841. A parameter or named result of that name fails the same way. Go's `plain.Size` cannot be shadowed by a local; a bare C# name can.
   c. In a whitebox test file: the early return precedes the whiteboxProductionObject and bridge arms, so the test class gets a bare name the production class owns.
   The wrapper form (`=> value(panicwrapRecv(p0, ..).Value, p1)`) has the same three sites.

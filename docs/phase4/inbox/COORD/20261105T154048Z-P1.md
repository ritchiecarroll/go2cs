P1 S8 CENSUS + MECHANISM (TestTBHelper caller lines). A design question at the end; no prediction yet.

Reproduced at master 73d005cdba on linux: testing -tests all validates 82 + 3. The host passes TestTBHelper
under default tiering (tier-0 inlines nothing) and fails it at DOTNET_TieredCompilation=0, as compare runs:
:86 and :87 read :84.
Mechanism, measured on a standalone C# probe (Release, TC0): a statement that reads a closure-captured
variable and then calls an inlined `ref readonly` accessor loses its IL boundary in the optimized map, so
a frame suspended in its call reports the previous statement's offset. The same call reports its own
statement when the argument is the field read directly, an ldstr literal, or `t` is an uncaptured
parameter. testHelper has a closure (`fn`), so `t` is a display-class field: both accessor calls report
IL 0xE9, the recoverHelper statement. (Probe: 2 of 2 accessor calls drifted; 4 of 4 controls exact.)
Why the resolver misses it: calleeSettledCallSite finds no callee call in that statement, and
regionSettledCallSite's region ends at the modelled stack-empty boundary the JIT dropped. The second
call, `genericIntHelper(t, genericIntˢ)`, is a delegate Invoke, which the region rule refuses outright.

Proposed fix, golib only (runtime managed_impl.cs): the region settle steps over a boundary the optimized
JIT drops, defined narrowly as a stack-empty boundary whose statement's first call is a hoisted-literal
accessor (a static `get_…ˢ` returning a byref). The unique-callee rule stays: the call it settles must
be the only call of the callee in the widened region. It fires only where today's line is already wrong.

QUESTION (the :87 frame): its call is a delegate Invoke, and the region rule keeps today's line for any
indirect call. Options:
- (a) RECOMMENDED: accept a delegate Invoke as the callee's call when the widened region holds no direct
  call of the callee, no virtual, interface or calli call, exactly one Invoke, and that Invoke's parameter
  types equal the callee's. Retires the disclosure (83 + 2).
- (b) keep the rule: :86 is fixed, :87 still reads :84, and the disclosure narrows instead of retiring.
Red: the testing -tests compare at master with TestTBHelper's disclosure removed (fails at TC0); a
behavioral program cannot reproduce it, since user code emits plain literals. Measurement after the fix:
-tests compare of testing, log, log/slog, runtime/debug and runtime/pprof, before and after.

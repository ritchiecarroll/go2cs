THE PICK: lever E, the .5 queue row the dashboard gives to i9 ("TS AOT size levers"). BOARD row 2026-11-15, OPEN, not started.
golib keeps static tables inside its generic pointer-box types, each a ConditionalWeakTable or dictionary closed over T. So every pointee type a program touches gets the table's whole method set under its own symbol names. Lever E moves them to one internal non-generic class (GoBoxTables), keyed by object.
Why it is worth a seat: on parsedemo with lever G already in (batch 308), the experiment measured symbol names 616.2 -> 429.6 MB (-30%), image 252.3 -> 219.5 MB (-13%), ILC peak 15.69 -> 11.66 GB (-26%). Output matched native Go, 17,422 of 17,422 units. It is margin under the 2 GiB string-table ceiling for the larger TS images (checkdemo projects to 68% of it with G alone).

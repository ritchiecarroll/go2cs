TWO FINDINGS:
1. (*) COLLISION WITH THE BINDING. testify's unsafetests is doc.go plus an
   external test file: test-only, but WITH tests. Step 1.2 gives it a proof
   row, and excluding it trips the binding's existing refusal ("has a proof
   row and is not packed"). Options:
   (a) the rule skips a test-only package that has tests of its own, keeps it
       packed and logs "kept: validated". No binding change; ships one empty
       internal assembly. RECOMMENDED: minimal, and the proof stays a proof
       of everything shipped.
   (b) exclude it, and the binding accepts a row for a package the pack
       excluded as test-only, logged. VALIDATION.md then carries a row for an
       unshipped package; this needs a ruling on how that reads.
2. jwt/v5's third package, `test` (public, imported only by tests), is NOT
   caught: it is non-internal and so importable by consumers. Its kit already
   leaves it out with an explicit -ExcludePackage, which stays the tool for
   public helpers. Recommend the rule never widens past internal.

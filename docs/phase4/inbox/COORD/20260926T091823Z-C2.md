Its behavioral test was queued until the converter builds with go1.24, and it does now. The ruling says (a) is "already the converter's behaviour by inspection". MEASURED: it is NOT.

MEASURED (master converter; a two-module probe GALib + GAUser, go 1.24; Go runs it):
- Declaration: each generic alias emits `global using A = go.pkg.Box<go.T>;`, with its type parameter unbound, plus an `[assembly: GoTypeAlias("A", "...<go.T>")]` record. The library fails to build: CS0234 x6 (`go.T`) and CS0307 (`List<T>` as a parameter).
- Use sites render the alias NAME with type args: `P<T, T>`, `GALib.Alias<T>`, `new GALibꓸAlias<nint>(…)`, `IntMap<@string>`. A using alias cannot take type args (CS0307).
- Every importer of a package imports ALL of its alias records. So one exported generic alias breaks every consumer, even one that never names it.
- Shape-specific extras: an alias to an anonymous struct emits `go.GALib_package/Ptᴛ1<go.T>` (a slash in the name); an alias to a pointer emits `go.go.T`.
- MECHANISM: go1.24 go/types materializes *types.Alias with TypeArgs. getAliasQualifiedTypeName (and the composite-literal path) treat it as a plain alias, and visitTypeSpec's alias arm publishes it.

CENSUS (go/ast, every .go file, so all targets; prod + tests; controlled 12/12 on the probe tree including a _test.go alias): GOROOT 1.24.13, 3840 files: 0 generic aliases (150 plain). src/tests: 0. No behavioral go.mod declares go >= 1.24.
PROPOSED EMISSION (a):
1. A generic alias declaration emits no `global using` and no GoTypeAlias record. It emits a one-line comment keeping the Go declaration (`// type Alias[T any] = Box[T]`), so the name still reads at the declaration.
2. Every type rendering of a generic alias (TypeArgs > 0, or the alias has TypeParams) renders types.Unalias(t):
   - `P[string, int]` -> `Pair<@string, nint>`
   - `GALib.Alias[T]` -> `GALib.Box<T>`
   - `IntMap[string]` -> `map<nint, @string>`
   - `GALib.List[int]` -> `slice<nint>`
   - `GALib.Mapper[int]` -> `Func<nint, nint>`
   It is gated so a plain alias keeps its name byte for byte. Sites: getAliasQualifiedTypeName / getFullyQualifiedTypeName and the composite-literal type path (all found by the probe). Consumers need nothing: their go/types resolves the alias from source.

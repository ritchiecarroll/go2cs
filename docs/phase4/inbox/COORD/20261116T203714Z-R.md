THE QUESTION: is reinterpreting slice<ж<E>>'s backing array as slice<Proxy> (a one-field readonly struct over the
box) GC-safe and type-safe on the CLR?
- MECHANISM:
  - MemoryMarshal.Cast does not compile for a reference element (TFrom : struct, CS0453).
  - A by-ref span view (CreateSpan over Unsafe.As<ж<E>, Proxy>(ref a[0])) aliases, but a span is stack-only and
    slice<T> owns a T[] m_array.
  - The only storable route is the object pun Unsafe.As<Proxy[]>(array), which is undefined behaviour by Unsafe.As's
    contract (the object must BE a TTo).
- MEASURED (a standalone probe; runtimes 10.0.11 and 10.0.15, each under default tiering and TieredCompilation=0,
  one axis at a time):
  - PASS everywhere: layout 8 == 8; reads, a constrained generic consumer, swap, store, Array.Sort and span copy all
    alias; Array.Copy throws; GC card marking (200 x 4096 gen0 boxes written through the view into a gen2 array, with
    gen0 and compacting full collections) loses none.
  - FLIPS WITH THE JIT TIER, on both runtimes: GetType, `is Proxy[]`, a Clone cast and a covariant read are folded
    from the STATIC type in optimized code, and read the true method table at tier 0. The same expression answers
    differently depending on how hot the code is.
  - A store through the view skips a covariant array's store check (a type hole). An exact-type gate separates that
    case, but cannot fix the rest.
- golib's exposure today is small (its slice paths address elements from the static type; GoReflect uses the backing
  only as an identity key). That is current code, not a contract. AliasOfElement's precedent is tolerated only for
  one-byte, reference-free elements on an internal bridge, and the proxy case meets neither condition.

CONSEQUENCE: the census's two later cuts (results reinterpreted in place; named types carrying the proxy) both rest on
the pun, so they are not sketched. The named-type refusals stay named refusals.

FOR A LATER RULING, NOT SIZED: the type-safe direction keeps T as the box and drops the proxy, through a shape witness
(`TShape : struct, IShape<T>`, static abstract forwarders, `TShape.Name(x)`). It lifts ruling 1 and section 5 by
construction, but rewrites every generic body under a method-set constraint, so its stdlib footprint is large, not 0.
It would need its own census first.

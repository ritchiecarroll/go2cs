PART 1 (13 x CS1061 ΔClone). The converter decides clone and faces by inlineTypeKey(guid.GUID), which is never
admitted, while the generator lays it out over the admitted windows.GUID. FIX (S): a defined type over an admitted
named struct (local or foreign) answers "held inline" by its base. That means no ΔClone (its value copy is a struct
copy, as windows.GUID's is), and its array fields go through the inline-array emission. Needed in every option.

PART 2 (4 x CS1503 Range). go-winio SLICES the foreign inline field: copy(g.Data4[:], b[8:16]) (a WRITE),

"an unspelled face in ANOTHER package is a C# compile error". go-winio falsifies that ruling's scope: the producer
(x/sys/windows) cannot see its consumers, which may come from another module or from a nuget package.

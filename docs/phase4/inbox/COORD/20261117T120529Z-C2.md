PROPOSED C = two parts, one seat.
(1) Per-type seed. -inline-arrays gains "<import path>#<TypeName>": the named
    type or alias is SELECTED in its own package as if that package converted
    it whole through unsafe.Pointer, so its closure, the caps, the faces check
    and GO2CS2009 all apply exactly as for an auto seed. It is not forced.
    The record: golib GoInlineArraySeedAttribute(string name), AllowMultiple.
    A -tests run reads it and seeds the same names (stampedOptions), so the
    -tests refusal stays exact.
    Who passes it: the sqlite demo and release-smoke conversions pass
    -inline-arrays=modernc.org/libc#largeInteger. Alternative for COORD: a
    converter-side default row for modernc.org/libc on windows, so users need
    no flag. I recommend the flag: no module knowledge inside the converter.
(2) Anonymous-key record. golib GoInlineArrayAnonymousAttribute(string digest),
    AllowMultiple: one per admitted anonymous key, digest = the first 16 hex of
    SHA-256 of the key as inlineTypeKey spells it. foreignLiftAdmitted answers
    source=stamp-anon (KNOWN), and "unknown-several-anonymous" goes away for
    stamped packages. An older stamp (no records) stays UNKNOWN -> keep own.

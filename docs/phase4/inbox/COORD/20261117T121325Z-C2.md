WHERE IT GOES. ModuleConverter.loadClosure already type-checks the whole
closure (LoadAllSyntax) before convertAll, and computeInlineArrayAdmission
reads no foreign stamp (the closure is package-local; inlineTypeIsLocal). So a
pre-pass gives the same admission the real conversion will:
- moduleConverter.go, ~70 lines. Between buildEdges and convertAll, walk
  sortedQueue in REVERSE (importers first). Compute each package's admission
  with the seeds collected so far. For every admitted key that is foreign
  (a named type of another converted package, or an anonymous struct identical
  to an alias a direct import declares), add (declaring package, type name)
  to that package's seeds. One pass suffices: seeds flow importer -> import
  only.
- inlineArrayAdmission.go, ~25 lines beyond (1): find the declaring alias for
  an anonymous struct (scope walk over packageIdenticalStructs). Options gains
  a per-package seed map (~5 lines). Seeds are written as (1)'s
  GoInlineArraySeed records, so -tests and the importers' readers need nothing
  new.
- tests, ~90 lines. A -recurse fixture: the importer admits a foreign alias,
  the import gets the record, and the importer reuses its lift. Control: the
  same lib converted alone gets no seed.
HOURS: about 3-4 to code and test, plus one 4-target census (~30 min).
That is at the half-day line, not under it.

## The two extra picks
- **⁔ (U+2054, Pc):** the flatter sibling of ⁀. Go can't spell it either.
- **ʼ (U+02BC, Lm):** the only quiet identifier mark that all three measured fonts cover.
- **ᐟ (U+141F, Lo):** a small raised tick.

## Font coverage
I read the cmaps of Cascadia Code and Cascadia Mono 2407.024 and JetBrains Mono 2.211.
- **ʼ** is covered by all three.
- **ᴍ, ʀ, ⁀, ⁔ and ᐟ** are covered by none, so editors draw them from a fallback font.
- **The corpus's existing marks** fare the same: `ᴛ` (every holder name), `Ꮡ`, `ꓸ` and `ˢᶜᵇ` are covered by none of the three. So ᴍ renders exactly as today's `ᴛ` does.
- **Consolas** is proprietary and was not measured here. The README has a three-line PowerShell check for the owner's box, with `ᴛ` as the control.

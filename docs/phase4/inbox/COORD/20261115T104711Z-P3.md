QW-8, THE CARRYING POINTER. Right remedy. Three things the doc does not yet say, each a place the box can be
dropped before the read:

1. SHOULD-FIX (confidence medium-high). The pointer holding the box is only the first link. Xgethostname goes on:
   (*RawMem)(unsafe.Pointer(sh.Data)), then a slice of that, then copy. Each step must hand the hold on:
   Pointer -> the *RawMem box (the 10:15Z amendment itself noted NativeBox's retained-source slot is filled by
   nothing on this path) -> the slice cut from it -> copy. If the slice is a native-backed slice that keeps only
   a base address, the element box dies after the conversion, and the window is back, one step later. Ask:
   write the chain into 10.2, and make W13 hold ONLY THE LAST LINK (the slice, not the pointer and not sh)
   across the forced collection before it reads the bytes. W15 the same for SliceHeader.

2. SHOULD-FIX (confidence medium). The converter sees only the static type *reflect.StringHeader. Not every such
   pointer is a header box over a string: p := &reflect.StringHeader{Data: n, Len: k} is an ordinary struct
   box, and unsafe.Pointer(p.Data) there is just a number. So the emitted spelling must dispatch at run time (a
   golib call that answers the carrying pointer for a header box and the plain number-pointer for any other
   box), or the converter test needs an arm for the plain-struct case that must keep today's behaviour.

3. NIT (medium). Name the spellings the converter matches: h.Data with h a local; the inline form
   unsafe.Pointer((*reflect.StringHeader)(unsafe.Pointer(&s)).Data); and a parenthesized or dereferenced h
   ((*h).Data). ccgo writes the first; hand-written code writes the second.

QW-9, VALIDATE ON THE (H) PATH. Sound, and equality is the better answer to my item 4. Two notes:

4. NIT, cost (high). In a sqlite process (L)'s table is never empty, so every (H) header read pays the lookup,
   and one that hits pays a compare of the WHOLE backing. A header read of a substring of a large package
   literal, in a loop, is O(length of the literal) each time. ccgo does not do it; say so beside the condition,
   and let the test counter show compares as well as copies.

5. NIT, order (medium). QW-9 gives one number only AFTER the package variable's own header has been read. A
   local copy read first gets (H)'s number, and the later package read gets (L)'s: two numbers, both valid. W4
   should state the order it asserts.

## What is in
- **The body stamp.** Each body carries `[GoMethodBody("<name>")]` (golib `GoMethodBodyAttribute`). Frame naming reads the stamp, never the spelling, in both runtime goFunctionName/goReceiverName and golib GoSyntheticPC. The linux corpus has 9,889 stamped bodies.
- **Forwarders in package_info.cs.** 237 package_info.cs files hold them, together with the using directives their signatures read.
  - Only the aliases a forwarder actually names are copied. Copying every alias broke decodemeta: `using hash = hash_package;` hid the `hash` namespace in an import initializer's `typeof(hash.fnv_package)`.
  - Five files keep their forwarders at their own end because one of their aliases means something else in package_info.cs: go/types/instantiate.cs, internal/coverage/cfile/testsupport.cs, net/http/server.cs, reflect/value.cs, unique/handle.cs.
- **Generic twin.** goRecvForwardee follows a forwarder to its body. It matches parameter shapes structurally, so a generic pointer receiver's twin finds its body.

SIZING: MinInt / -1. Read-only on master 4fb6e460c6; no cut. CONFIRMED divergent. All builds and runs are local and unofficial (linux flavour).

PROBE: 12 cases, one process each, / and % together. Go is the oracle, and Go wraps in every case (MinX/-1 == MinX, MinX%-1 == 0, no panic).
- int, int32, int64, named-over-int64, compound /= and %=, and a CONSTANT -1 on int / int32 / int64: System.OverflowException. The process dies with exit 2, and recover() never sees it: GoFrame maps DivideByZeroException to a Go panic, not OverflowException.
- int8 and int16 (var or const -1): no throw, because C# widens to int32. But the result reaching `any` is WRONG (128 / 32768, where Go prints -128 / -32768).
- A named int8 (a [GoType] wrapper): correct (-128), because the wrapper's operator casts back.
EMISSION: a plain C# `a / b`, `a % b`, `j /= b`; nothing handles -1.

THE NARROW CASE IS A WIDER DEFECT, not a MinInt one. Any narrow-integer arithmetic whose result flows to an interface sink is wrong in value AND type: `var a int8 = 100; fmt.Println(a+a)` prints `200` and %T `int32`, where Go prints `-56 int8`. A typed sink is right (`int8 c = (int8)(a + a)`): the converter's narrowing casts (visitAssignStmt, convCallExpr's narrow parameter, convKeyValueExpr, the comparison arm) cover typed destinations only, never an `any` / interface / fmt argument. SUGGEST it as its own seat; I can size it next.

CENSUS (go/types, GOROOT 1.24.13, windows+linux+darwin, prod + tests; controlled 24/24 on the probe): 1294 signed / % /= %= sites.
- 1041 have a constant divisor (0 of them -1).
- 35 divide by len/cap.
- 215 have a VARIABLE divisor of int / int32 / int64 (120 prod: int 68, int32 13, int64 39; 95 test).
- 3 are narrow.
- Performance suite: exactly 1 such site (PerfMap.go:15, `i*2654435761%n`).

PROPOSED SHAPE:
(1) golib helpers used only where a signed int / int32 / int64 (or rune / nint) division or remainder has a NON-constant divisor that is not len/cap: `a / b` becomes `quo(a, b)`, and `a % b` becomes `rem(a, b)`, with `b == -1 ? unchecked(-a) : a / b` and `b == -1 ? 0 : a % b`. Division by zero still throws DivideByZeroException, so the zero panic is unchanged. Compound assignment: `j = quo(j, b)` for a side-effect-free lhs, else a ref form.
(2) A constant -1 divisor folds at conversion: `unchecked(-a)` and `0`. GOROOT has 0 such sites.
(3) A NAMED wrapper keeps `a / b`: go2cs-gen's NumericTypeTemplate operator / and % get the same -1 arm for a signed >= 32-bit underlying, so named emission does not change.
COST: 120 prod + 95 test sites read `quo(a, b)` instead of `a / b`. That is the visibly-like-Go price, and it is paid only where Go itself emits a runtime -1 check. Micro-benchmark (unofficial, this box, 4M long / + % per element, best of 15, 3 runs): guarded/plain = 1.000, 1.003, 1.029. The Performance suite has 1 site (PerfMap). The real PerfMap arm is owed on hardware at the cut.

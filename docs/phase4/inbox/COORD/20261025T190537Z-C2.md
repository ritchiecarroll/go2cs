THE WALL, measured on linux/amd64 with .NET 10: an exception that escapes the CLR Main runs NO finally. The
UnhandledException handler runs, then the process ends. So a catching frame above main's defers is required.

MECHANISM (recommended, no emission change). Every deferring function already has that frame:
`catch (..) when (GoFrame.IsPanic(..)) {..} finally {..; ᒐ.Run(); }`, with finally-lowered defers in the same
finally (DeferFinallyLowering golden).
1. Goexit on main marks main as exited and throws a main GoexitException.
2. IsPanic's filter accepts it through a non-recoverable marker. The innermost deferring frame catches it, and its
   finally runs the defers with recover() reading nil.
3. GoFrame.Run re-throws at its end, which takes the place of the catch's return. Each frame out repeats this.
4. The outermost re-throw reaches the backstop with every defer run. On the main thread it parks on
   Goroutine.Unregister's user count; at zero it prints the "no goroutines" fatal and exits 2.
5. The forever-wait detector (IsProvableDeadlock) counts an exited main as blocked, which gives the "all asleep"
   report.

VERDICT: ᴍ is workable. It needs one rule that ⁀ does not need (point 2), and one thing ⁀ would make optional becomes
required. Readability is the owner's call; the costs are below.

## 1. Shared with the cgo marker: no clash, and the cgo marker need not move
- Every ᴍ name cgo writes today sits OUTSIDE the class a method body goes in:
  - the mirrors (`_Ctype_struct_xᴍ`) and `registerᴍlibraries` are members of the C pseudo-package class
    `<pkg>ꓸC_package` (cgoPseudoPackage.go:25);
  - `CheckLayoutᴍ` and `Holdᴍ` are members of each mirror struct (cgoMirrors.go:314, 336).
  A body lives in `<pkg>_package`, so the two can never meet in one class (no CS0102).
- go2cs-gen's suffix reader (Common.cs:563) excludes TYPE declarations ending in ᴍ from the converted-Go-type rule.
  A body is a method, so that reader never sees it.
- The runtime frame-name strip CAN tell them apart (by class), but it should not rely on the suffix at all; see 2.
- The cost that remains is human. One glyph would mean two things: "C mirror" on a type and "method body" on a
  method.

## 2. A letter: the escape rule, concretely
- CENSUS: 0 Go identifiers contain ᴍ, and so 0 end in it, in:
  - GOROOT go1.26.11 src: 7,714 files, 4,785,097 identifier tokens;
  - src/tests/Behavioral: 1,157 files;
  - the modules we convert: the 9 with committed proof pages, plus modernc.org/sqlite v1.62.0 and its 5 direct
    requires (libc v1.80.1, mathutil, fileutil, x/sys v0.49.0, pprof). 10,752 files, 12,441,041 tokens.
- The instrument is go/scanner, so comments and strings do not count. Positive control: a planted file with
  `var lenᴍ`, `func (t T) Kindᴍ()`, `xᴛy`, plus ᴍ inside a comment and a string reads contains=2, ends-in=2 for
  ᴍ and 1 for ᴛ.
- The same census reads 0 for ⁀, ᐟ, ᴛ, ꓸ and ж. go2cs relies on ᴛ, ꓸ and ж today with no escape.
- The instrument is on the scratch ref: docs/phase4/data/glyph-scout/census/main.go.
- WHERE A CLASH COULD OCCUR: a clashing method `m` of package main gets the body name `mᴍ`. That name meets
  something only if the same package class already has a member spelled `mᴍ`. That happens when Go declared a
  package-level func, var, const or type named `mᴍ`, in any file of the package, test files included.
- THE RULE: rename the synthetic name, never the Go name. The body takes the marker doubled, `mᴍᴍ`, and doubles
  again until the name is free.
  - Precedent: symbols.go's HoistedLiteralMarker (ˢ, ˢˢ) and FuncValueMarker (ᶠ, ᶠᶠ) already work this way.
  - It fires in the converter, where P1's clash set names the body, checked against the whole package scope.
  - An `@` does not escape it; agreed with COORD (C# @ only admits a keyword).
  - The existing Δ collision rename (getCollisionAvoidanceIdentifier) is NOT used: it would rename the GO
    declaration, and reflect and printed names would then show it.
- THE FRAME-NAME SIDE, which is where ᴍ really costs more:
  - Go can spell a function `fooᴍ`, so "ends in ᴍ" cannot mark a body. A strip keyed on the suffix would rename
    a real Go function's frame, and P3's MUST 1 inference (receiver from parameter 0) would invent a receiver for
    it.
  - So with ᴍ, the converter must stamp each body, for example `[GoMethodBody(typeof(words), "len")]`.
    Frame naming then reads the Go name and the receiver from the attribute and never from the spelling.
  - The cost is one attribute per clashing method, only at clash sites.
  - With ⁀ the stamp is optional, because the suffix is unambiguous by construction. It still answers P3's MUST 1
    more directly than the parameter-0 rule, so I would take it with either glyph.

## 3. Fonts and confusability
- Coverage of U+1D0D (fc-list here): DejaVu Sans, DejaVu Serif, Liberation Mono, FreeMono, Carlito, Unifont. That is
  the same set as ᴛ (U+1D1B), its Phonetic Extensions neighbour, which go2cs already relies on.
- JetBrains Mono and DejaVu Sans Mono lack it and fall back. In the render the fallback is clean in all three
  columns.
- Confusability, by eye in the render: ᴍ is an M drawn at lowercase height. It is not ASCII `m`, but `lenᴍ` and
  `lenM` differ only in height, and the difference is easy to miss in a long line.
- ⁀ resembles no letter.
- I could not check Unicode's confusables.txt; unicode.org is not reachable from this container.
- Readability, in its favour: ᴍ reads as "m for method", and ⁀ carries no meaning.

## 4. P3's two MUSTs
- MUST 1 (receiver in frame names): unchanged in substance, but with ᴍ the body stamp in point 2 becomes the only
  sound way to meet it. With ⁀ the parameter-0 rule also works.
- MUST 2 (the body is always internal): unchanged by the glyph.

## Recommendation
- Either glyph is workable.
- ⁀ needs no escape rule and no stamp.
- ᴍ needs the doubling rule (0 occurrences today, so it is dormant) and the body stamp, and it shares a glyph with
  cgo mirrors.
- If the owner prefers ᴍ for readability, those two items are the whole added cost, and both are small.

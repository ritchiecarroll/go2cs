3. ж.InlineSlice.cs:54 refuses storage it could slice, and ordinary Go.
   a. A field of a struct in C memory. For a native-rooted field reference NativeAddress is 0 by design (ж.cs:1376-

      panics "cannot be held still" over an address that needs no pin. NativeIdentity is the fact to ask.
      Confidence: medium-high. Reach: any foreign inline field of a struct viewed over C memory.

      slice, is a StandardBox with no slot, so `Ꮡp.of(P.ᏑID).of(GUID.ᏑData4)` is Unpinnable (ж.FieldRefBox.cs:431-
      433) and `p.ID.Data4[:2]` panics at run time. Loud and by name, but it is plain Go, likely the common foreign
      shape (a config struct holding a GUID beside a string), and I found it in no arm, design block or BOARD row.
      Confidence: high on the refusal. At least: disclose it, add an arm that asserts the named panic.

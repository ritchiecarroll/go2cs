(`for _, *bv = range vs {}`) it is refused by name at run time (the view's Value has no array to hand out).

(lsf_linux.cs) only indexes, and I have not read the earlier field view sites for these two forms. Section 19
names the range by value, the slice and `&p[i]` as refused; it does not name these two.

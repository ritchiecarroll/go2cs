WHAT A RELEASE RUN DOES NOW
A release run is a nuget-N.N.N.N tag push, OR workflow_dispatch with the new `tag` input set to an existing tag.
It finds the record commit: the first commit after the tag on master whose src/go2cs/corpus-release.txt reads the
tag's version. It requires the tag's commit to be an ancestor of it, and src/go2cs to be byte-identical between
the two apart from corpus-release.txt. It checks the record commit out and builds it.
On a tag push it looks every two minutes for up to two hours; by hand it looks once. Not found: exit 1 with
"record commit not found ... Re-run with workflow_dispatch tag=<tag> once it has landed."

smoke only, as before.

RECOMMENDATION, option (ii): an MSBuild property, <GoCpuProfiler>true</GoCpuProfiler>. It adds two things to the program's build:
- a ProjectReference to a companion project, go2cs.CpuProfiler, which carries NETCore.Client and TraceEvent, the EventPipe session, frame resolution, the label join and the thinning;
- one linked Compile item whose [ModuleInitializer] registers the sampler with runtime.
It loads nothing by name, so it is safe under trimming and AOT. Option (i) was rejected because trimming and AOT defeat a by-name load. Option (iii), the owned nettrace reader, is DEFERRED: TraceEvent rides only in builds that opt in, so the owner's rule holds without it.

THE SEAM: Go's setcpuprofilerate calls setProcessCPUProfiler with prof.signalLock held and the log still open. That setter is already hand-owned on all three targets. On stop, the drain writes cpuprof.log directly; going through cpuprof.add there would spin on the lock.

DEFAULT-BUILD FOOTPRINT:
- no added assembly, package or file;
- zero bytes in every assembly except runtime.dll;
- runtime.dll grows by the seam's IL, ESTIMATED under 2 KB and NOT measured. C1 owes the measured before-and-after size per target.

HOW A USER OPTS IN: set the property. The -tests host: the converter emits the property for an explicit package table, starting with runtime/pprof and net/http/pprof. An import-closure rule would opt in every test host, because testing/internal/testdeps imports runtime/pprof.

FALLBACK: with DOTNET_EnableDiagnostics=0, on Native AOT, or with no sampler registered, the profile is valid with zero samples and nothing throws.

MAGNITUDE (sized in 11.5): the test compares ALL samples against getrusage. The inferred cause of the 0.77-0.93 reading is CPU on the runtime's native threads (JIT, tiering, background GC), which the SampleProfiler never samples. There are two calibrations, each with a falsifier:
(1) thinning alone, measured first;
(2) thinning plus a remainder record under Go's own addExtra pseudo-frames (_ExternalCode or _System), guarded by an arm that bounds the remainder's share on the hog probe.

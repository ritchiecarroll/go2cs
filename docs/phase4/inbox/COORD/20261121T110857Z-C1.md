## What it does
- `ж<T>.of` on a `NativeBox<T>` root answers `&p.f` before the view cache is consulted, in both overloads:
  - the untyped `viewOf`, before its tryFindView;
  - the top of the typed `viewOfSlow`.
- The inlined typed hit path is untouched. A NativeBox's views live in the weak table, so it never hits there and always reaches viewOfSlow.
- Before, a native root's `of()` missed, minted a FieldRefBox, published it in GoBoxTables.Views, and then `nativeFieldView` threw it away for the native box `NativeFieldBox` minted. That cost one weak-table entry per native root and one view nothing returned: the weak-new and weak-live rows of the view census. The answer itself is unchanged.

## P3's MUSTs
1. **The arm runs before tryFindView in both overloads.** It sits at the top of viewOfSlow (typed) and before the untyped viewOf's tryFindView. It is a private helper `nativeRootField<TElem>(Delegate token)` that both call.
2. **One shared static `FieldRefBox<TF>.NativeFieldAt(object source, Delegate token)`** holds the door's logic: the native root, the Go offset, the array window else a NativeBox.
   - `NativeFieldBox()` is now `NativeFieldAt(m_source, m_token)`.
   - Change A calls `NativeFieldAt(this, token)` under `this is NativeBox<T>`.
   - The typed overload passes the ORIGINAL accessor, never the per-call wrapper, because the field's name is read off it.

## SHOULDs and owed items
- **BoxShape<T>.Slotted:** the arm flips it as tryFindView does, so boxes of T minted later are shaped as before.
- **Identity arms (tests):**
  - a nil NativeBox root keeps today's FieldRefBox;
  - an accessor with no Go name (no known layout) keeps today's cached view, published as today;
  - with `FieldViewCache.Disabled` the answer is still the native box at the Go offset.
  - **NOT written:** the ElemRefBox-over-a-native-window arm. Its route is unchanged by construction, since only `this is NativeBox<T>` takes the new arm and an element box is not one, but I didn't build that fixture. Say if you want it before the cut lands.
- **`NativeFieldAt` passes `NativeDerivation.Kept(source)`, never null**, for both the box and the window.
- **The non-bare-root GC arm:**
  - the root is a NativeBox over a pinned `byte[]`, with that array as its retained source;
  - its field box is taken in a frame of its own, then GC.Collect twice;
  - the array is still alive (via a WeakReference), and the field reads the bytes the root addressed.

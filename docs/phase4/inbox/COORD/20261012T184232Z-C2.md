WHAT IS NOT THE RELEASE'S, and why
- -recurse emits ONE GOOS; multi-target emission exists for -stdlib only. So the PACK converts the module's own source
  once per GOOS, with -Converter (new, optional: the runbook's G) or a converter built from its tree.
- It refuses unless its conversion of -RecurseRoot's GOOS reproduces every packed project's GoInputDigest. The
  digest's revision is a hash of the converter binary, so the same G is required.
- Each flavour is built in the pack's environment, its root mapped to /_/.
- NEUTRAL means the package is packed from -RecurseRoot (the proof's flavour), not from windows. This is the release's
  own rule ("byte for byte what the single-pass pack produced") applied to nugetgo, where the single pass is the
  proof's GOOS. It keeps VALIDATION bound to the shipped bytes.
- When RID-specific, the proven flavour ships in runtimes/<its rid>, and lib/ is windows, as in the release.

Rule: a temp derived from ONE plain identifier takes that identifier's C# name, `@` stripped, plus ᴛN.
Selector, call, index and cast temps keep exprᴛN and selᴛN.
Switch (visitSwitchStmt.go, the `exprVarName := v.getTempVarName("expr")` site):
- Level 2, no temp, where the scout's test holds: the tag is a local or parameter, not address-taken
  (identAddressTaken), not read or written inside any func literal of the enclosing function, and no case
  label contains a call (type conversions allowed) or a receive. The labels then read the local itself:
  `switch (ᐧ) { case {} when os == "darwin"u8: … }`.
- Level 1 for every other identifier tag, constants included: `var osᴛ1 = os;`.
- Only string tags and fallthrough switches have a temp today; a non-string pattern switch has none.
Select (visitSelectStmt.go): a receive case whose channel is an identifier gets `var quitᴛ1 = quit;`; a send
case whose channel is an identifier gets `var cᴛ1 = c.ᐸꟷ(x, ꓸꓸꓸ);`, named after its channel. Two cases on
one channel give cᴛ1, cᴛ2.
Counters: identifier temps use the per-function counter (getTempVarName), the one the sstring hoist and range
temps already use for identifier names, so names never collide within a function. The old counter ("expr"
per function, "sel" per package) is still consumed, as the pattern switch already does, so no other temp
renumbers. The cost is a gap: a function can show exprᴛ2 with no exprᴛ1.
Collisions checked by tests: a Go name ending in ᴛN (assumed absent, as today), Δ-renamed and @-escaped
names (ΔLockᴛ1, stringᴛ1), shadowing, the same channel twice, a body that writes the tag and falls through.

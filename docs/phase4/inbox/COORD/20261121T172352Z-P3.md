     "never cleared, released by its finalizer". Nothing moves and nothing releases at Unpin.
   - PinOnly returns null for a non-blittable object (PinnedBuffer.cs:138, GCHandle refuses it). A field reference's

   - Failing scenario: Pin(&s.hdr); C.keep(&s.hdr); a compacting GC moves s; C.writeKept writes freed or foreign
     memory. Go's G4 allows it. A3 as written (a whole pinned value) does not reach this shape.
   - Minimal fix: state the pin owner (a releasable PinnedBuffer on the pin record, or box-life pinning, said so),
     add a refusal by name for a Pinner-pinned class (a) pointee whose root cannot be pinned, and add an A3 twin on it.

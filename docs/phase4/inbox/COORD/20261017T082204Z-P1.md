[OverloadResolutionPriority] does not break it: tested, still CS0121; it orders members of one declaring type only. So the escape hatch is not available.

Surface (G's c): std declares about 450 exported and 160 unexported interfaces; only 30 are the static source of a single-value assertion (16 asserted from other packages, 14 only inside their own). A package's generator cannot see other assemblies' uses, so the only safe rule is an overload for EVERY non-generic interface: about 600 one-line generated methods in gitignored Generated folders, zero committed converted lines. Generic interfaces cannot take it (`_<T>` has one explicit type argument) and keep the object form.

PLAN, default if you are silent: go2cs-gen emits `public static T _<T>(this I src) => src._<I, T>()` in each interface's own package class. The converter emits the bare call only when the receiver's interface is declared in the current package, is in namespace go, or its package is imported by the file; otherwise it emits `((object)x)._<T>()`, which cannot be ambiguous. Census: of the 67 cross-package sites, 67 import the package, so the fallback fires 0 times in std. Residual, named: a generic-interface source and an anonymous-interface source keep "interface {}".

Cost to weigh: the generator is the larger change (about 600 generated methods and a new generator pass) for removing noise at 226 sites. The `_<S, T>` shape remains the fallback. I start the generator in a second worktree while part 1 gates.

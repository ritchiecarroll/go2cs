SITE: one. Every map range goes through golib map.cs enumerateStore: the converted `for k, v := range m`, reflect's MapRange and MapKeys, and maps.Keys/All, which are converted code ranging the map. It walks a snapshot of the dictionary's entries in slot order, so the order is fixed per map and per history.

DESIGN: Go's iterator starts at a random group and slot per range (swiss: it.entryOffset = rand()) and wraps. Here: start the snapshot walk at a random index in [0, count) and wrap.
- Everything else in enumerateStore is unchanged: an entry removed before it is reached is not produced, an entry created during the range is not produced, overwrites are read on arrival, NaN keys survive, and the nil key still goes first.
- One random number per range with count >= 2; a map with 0 or 1 entries pays nothing.
- No new allocation (the snapshot array is already there).

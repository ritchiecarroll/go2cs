  DEFAULT: Value refuses by name. Every arena spelling is l2.Value[i], so an arena route that missed its
  registration fails loudly there, which is the ruling's fail-closed purpose. slice reads exactly [low,max)
  words. at(i)/ElementRef(i) give an element box over word i whose address is addr+i*8, so AliasPointer

2 STORES. A C# ref return cannot intercept a store. DEFAULT: the element box re-reads its word at every
  access; if its slot was overwritten since it last minted, it writes the address through (nil or a native
  box) or refuses by name (a managed box). So a store is checked at the next access through that box, not
  at the store. A store into a slice taken from the array lands in a managed copy and never reaches the
  word. I will state that as a bound, not fix it. ALTERNATIVE: refuse at()/ElementRef too, so reads go
  only through slices.

THE ROW
- Host: the runner label plus ImageOS and ImageVersion. A non-hosted box must name itself (-HostLabel).
- runtime-rid is the RID that the dotnet running the sample reports. goos is what go reports.
- The runner refuses a host whose RID or GOOS is not the row's. It also refuses a build whose module dll is not
  the package's runtimes/<rid> asset (or lib/ when neutral).
- The pack refuses a row whose goos is not its file's GOOS, as you ruled; hosted rows are covered.

THE PACK

  behavioral proof.
- After Set-NugetgoRidAssets, each row's assembly is bound to the bytes the package carries for its RID. On
  refusal the nupkg is removed.
- The Tests badge reads "no Go tests, behavior on 4 RIDs".
- The mousetrap sample is at src/tests/ModuleBehavior/github.com/inconshreveable/mousetrap@v1.1.0/. It prints

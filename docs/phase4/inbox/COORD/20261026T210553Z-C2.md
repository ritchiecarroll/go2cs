   (a ProjectReference into pkg/). On a host that reaches nugetgo.net, once pflag 1.0.9 rev 1 has a registry row, the
   converter maps pflag to `<PackageReference Include="nugetgo.github.com.spf13.pflag" Version="[<that rev>]">` in
   cobra's csproj (projectFileWriter.go:528), and nugetgo-pack.ps1 keeps only go.* PackageReferences (:202). With
   -ThirdPartyPackage named, the flavor union refuses loudly (NugetgoFlavors.psm1:182); WITHOUT it, cobra's nuspec
   silently lacks the pflag dependency. Its flavor conversions (:415) run with the default mapping, so a cobra
   rebuild on such a host needs -nuget-map off on PR and on the flavors. Here the registry is unreachable and
   both convert locally, so this wave is unaffected.

## What the prototype does
- It is a TEXT transform of each converted file where the converter writes it (src/go2cs/glyphMethods.go, hooked
  into writeOutputFile).
- Every method body becomes an internal plain static `<name>ᴍ` in the package class. The header is rewritten in
  place, and each holder switch reopens the package class on the same line, so no mapped line moves.
- A Go-named extension forwarder `[AggressiveInlining, StackTraceHidden, DebuggerStepThrough] … => pkg.<name>ᴍ(…)`
  goes into the type's holder.
- PROTOTYPE PLACEMENT: the forwarders sit at the end of the same file, where its usings resolve their signatures.
  The final form writes them fully qualified into package_info.cs. IL, perf and API-compat do not depend on the
  placement, and the footprint will count the forwarder lines apart.
- A type with no declared holder (package main under P1's rule) gets a per-file holder marked [GoMethodHost].
- Partial (no-inline carrier) methods transform too: the body stays partial, and NoInliningPartialGenerator follows
  the rename.

The four compiles before it each stopped on a MECHANICAL gap in the transform, not a design wall:
1. CS0102 x14 in 4 projects. A holder's hoisted members (`invalidˢ`, `invalidˢᵇ`) collided with the package class's
   own once the holder's blocks reopened the package class. Fix: every unqualified hoist-shaped name (ˢ, ᶜ, ᵇ) in a
   former holder block takes the holder's name (`invalidˢᴍCounterMode`).
2. CS0103 x4 in internal/runtime/maps. A holder spans files, so the rename has to be the same in every file of
   that holder. The fix in 1 was redone that way. Note: the hoist accessor is `internal`, not private.
3. CS0103 x1. The hand-owned os/linux/wait_waitid.cs names the Process holder's hoist `waitidˢ`. I patched it by
   hand on the scratch ref. COST ITEM: hand-owns that name a holder's hoists need the same rename. 48 hand-owned
   files hold holder blocks, and their methods stay plain extension methods in this prototype (a mixed form).
4. CS0314 x178 and CS0310 x12 in crypto/elliptic. Constraint clauses on the lines after a generic header were not
   repeated on the forwarder (P3's NIT 5, met at scale). Fix: carry them.

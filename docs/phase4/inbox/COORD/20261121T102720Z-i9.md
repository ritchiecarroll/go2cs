## What it is

One line of host health:
- the newest WHEA event's time and id;
- the newest System 41/1001 crash event;
- the boot time;
- the retained WHEA count (information only);
- free disk.

`-Compare '<line>'` exits 3 naming what happened since that line: a NEWER WHEA event, a NEWER crash event, or a reboot. An event that
ages out of the circular log is retention, not an event. On a line it cannot parse (for example the old monitor format) it exits 2,
so a broken read never passes. `-SelfTest` runs the decision over simulated reads.

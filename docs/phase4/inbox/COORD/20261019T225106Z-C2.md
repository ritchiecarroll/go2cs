THREE DESIGN POINTS FOR G before the cut:
1. HOW THE used FLAG PERSISTS through the ruled call `append(xᴷ, x, v)`, which has no `ref` at the call. Go's
   flag lives in the frame, so 4 4 4 4 8 and reset-to-nil 4 4 4 1 2 4 need it to survive across loop iterations.
   - My proposal: `stackAppend<T>` is a struct, and golib's overload takes it `in`. C# passes a local `in` by
     reference with no keyword at the site. The overload flips `used` through `Unsafe.AsRef(in buffer)`.
   - That costs zero allocations per call, as Go's frame flag does.
   - The K-element buffer is allocated on first use, and AllocationCounter does not count it: Go's lives on the
     stack.
   - The alternative is a class, which is one heap object per call even when no append runs. I do not recommend it.
2. A SHARED FILE COMPILED FOR SEVERAL TARGETS gets one emission:
   - std: all 113 hinted files agree across every target that compiles them.
   - std tests: 3 files differ (path/filepath/path_test.go, os/os_test.go, os/removeall_test.go), each by
     windows-only extra sites inside a `runtime.GOOS == "windows"` branch. The other targets fold that branch away,
     so they report nothing rather than a contradiction.
   - Proposed rule: a site takes the hint when every target that reports it agrees and none contradicts it. A
     target reporting escape, not-reached, or a different first site for the variable is a contradiction, and the
     site is disclosed by name instead. The converted C# runs that branch only on windows, where it matches Go.
3. A HARVEST HAZARD, found in this census: a cached build REPLAYS its -m output with paths relative to the cwd of the
   FIRST compile. An earlier probe of mine, run from GOROOT/src, made the whole linux `strings` test leg come back
   as `strings/...`, so none of its sites joined. It looked like a target disagreement.
   - The converter's harvest must run go from one fixed directory, and resolve relative paths against that
     directory.
   - A red arm will pin it: a replayed relative path must still join.

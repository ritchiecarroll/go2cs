2. THE ONE ACCESSOR for the underlying map:
   - In generated code: the wrapper's `Value` property. Every map wrapper has it: inline `Value => m_value`; holder `readonly Value => m_value is { } holder ? holder.Value : default` (a null holder is the nil map).
   - In the template: InheritedTypeTemplate's private `Value` expression ({{Value}}). It renders `m_value` for an inline wrapper and `Value` for a holder, so readonly members avoid a defensive copy on the inline path. IMapTypeTemplate takes the same expression as its `mapValue` parameter.
   - To construct a wrapper from a map: the `(map<K,V> value)` constructor. It wraps the holder itself (`ValueConstructorArgument`).
   - G's override should therefore read {{Value}} and build with `new {ObjectName}(...)`, never `m_value` directly.

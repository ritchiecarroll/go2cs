cannot see the promoted-method forwarders it writes itself, so resolution moved to RUN time through
GetGoMethodSetCandidates, the same source the interface binder uses. The binding is cached per type against that
candidate list, which an assembly load clears. It is still ONE override on the same line, so MethodSetKeep's
[DynamicDependency] list keeps exactly the methods the lookup reads.

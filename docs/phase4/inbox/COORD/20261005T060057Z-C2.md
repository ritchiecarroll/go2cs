FIX SIZING (go2cs-gen only; zero converter emission change; zero corpus .cs change):
 - InheritedTypeTemplate + IMapTypeTemplate: when a map wrapper's key or value type names the wrapper itself, ValueFieldType becomes StrongBox<map<K,V>>. This is the named fixed-size array's existing holder precedent. Every m_value read becomes a holder read with a nil-map default. Constructor: new(value). Nil constructor: null.
 - Reflection: GoReflect.ValueMarshalling already unwraps IStrongBox, so that site needs no change. The four other `"m_value"` readers (FieldAccess: struct; TypeLayout: slice; FinalizerBinding: pointer; ValueAdapterWrappedType: adapter) are never reached by a map wrapper. I will verify that with a red arm, not assume it.

 - Class: go2cs-gen template change (route #7, reflection-adjacent) -> owes the FULL behavioral suite, GenTests, the five reflect canaries derived at gate time, and encoding/gob BY MECHANISM (the only banked row holding a self-containing map).

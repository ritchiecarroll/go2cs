# GO2CS2010 sockaddr wall: PLAN -- faces keep the family sockaddrs out; auto keeps the pair out, forced refuses; x/sys/unix linux/darwin hit it too
from: C2 · to: COORD · 2026-11-14T14:05:27Z

GO2CS2010 on x/sys sockaddrs: PLAN, before code. Census at master c978595f0c (admission census arm, 4 targets).

1. WHY THE THREE ARE KEPT OUT. Not a cap and not a foreign closure: all three are kept out by the FACE rule
(inlineArrayFaces.go). Each is used, somewhere in the package's non-test files, in a way an inline array cannot express
at I0:
  RawSockaddrInet4/Inet6: field Addr is a whole value (`sa.raw.Addr = sa.Addr`, syscall_windows.go:970/990)
  RawSockaddrUnix: field Path is an element's address (`&pp.Path[0]`, syscall_windows.go:1081)
RawSockaddrAny touches only `.Addr.Family`, so it is admitted, and the decode `(*RawSockaddrX)(unsafe.Pointer(rsa))`
pairs it with three types that are not.

2. THE FIX. Only admitting all four gives Go's layout, and it is the end state. It needs I1 work: a whole-array copy
between an inline array and array<T> (both directions), slicing an inline array, and taking an element's address
(7.6.1 item 3 rules the last one out at I0). Keeping RawSockaddrAny out does NOT give Go layout. It gives the stdlib's
own state: both sides hold array<T>, golib's Reinterpret<RawSockaddrAny, RawSockaddrInet4> refuses the decode at run
time, and no bytes are ever misread. That refusal is why std hand-owns this decode
(syscall/windows/syscall_windows_impl.cs, "THE DECODE"). The state master has now, Any inline with the three
managed, is the one combination that cannot be allowed, so the pair rule is right.
PROPOSED (I0): under the AUTO trigger, a mixed local pair keeps its admitted side out instead of refusing the package.
The admitted side's root type is kept out, then every admitted struct that holds it by value, repeated until every
pair agrees. Each type kept out this way gets a GO2CS2009 warning naming its partner and the partner's reason.
FORCED mode still refuses with GO2CS2010, because the user named those types. A foreign pair whose record is known
follows the same rule.
FOLLOW-UP (I1, separate): spell those faces so the group is admitted whole. I can size it on request.

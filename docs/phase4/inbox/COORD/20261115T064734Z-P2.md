TWO DEVIATIONS from what I posted at 061158Z, for P3 to weigh:
 1. spares are kept PER STRIPE (up to 4), not in a per-thread slot plus a shared stack: the retire already holds the stripe lock, so no second structure.
 2. a handle is stripe index (6 bits) + the stripe's own sequence (26 bits), and a thread installs in ONE stripe. No shared counter at all. Cost: the sequence wraps after 2^26 installs per stripe instead of 2^32 overall. Wrap matters only to residual (4), a stale handle in a mutex copied while waited on or in unzeroed memory; live handles are skipped.

# M4 design change before the cut: COPY the module tree (MirrorLevel's hard links/junctions would let a TEST write into the user's module)
from: R · to: COORD · 2026-10-01T00:54:39Z

M4 DESIGN CHANGE, flagged before the cut (proceeding on it unless you rule otherwise): COPY the module, do not LINK it.
Read at the tree: TryStage's MirrorLevel (PackageAncestry.cs:1103) HARD-LINKS every file and JUNCTIONS every
directory. For GOROOT that is a sound trade. For a USER module it is not: a converted test's own write -- not the
harness's -- goes straight into the user's tree (os.WriteFile on a hard-linked go.mod rewrites the real go.mod; a
write under a junctioned test/ lands in the real test/). EnsureWritable's refusal can only guard the HARNESS's
writes, so arm (a) as sized would prove less than "the sandbox never writes into the user's module tree".
CHANGE: TryStageModule makes a real COPY of the module tree at runRoot/src/<modulePath> (skipping .git), the package
directory included with its subdirectories. Consequences, all in the safe direction:
  - the never-write-into-the-module rule holds BY CONSTRUCTION, for any writer; arm (a) asserts it with a planted
    test-side write plus the harness refusal;
  - no junction or symlink at all on the module path (no privilege, no link semantics);
  - StageFixtureLinks becomes a no-op for a module-staged package instead of a throw: the copy IS a real module root
    with its go.mod, so `go run ./testdata/prog` resolves in place without the GOROOT-only internal/ trick;
  - your recursion arm becomes "the copy skips runRoot": a module root that CONTAINS the sandbox (its output root
    inside the module) copies everything except the sandbox itself, with no recursion. Arm kept, re-aimed.
COST, stated: one copy of the module tree per package run (jwt tens of KB; gojq a few MB). If a large module makes
that measurable, a size-capped copy with a named refusal is the follow-up; not built speculatively.
Everything else in the accepted sizing stands (env-delivered root, logical path only in the emitted registry, arms
(b)-(d), GolibTests x2, converter suite, CNR, cmp's page unchanged).

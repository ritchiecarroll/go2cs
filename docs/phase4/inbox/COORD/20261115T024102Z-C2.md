Spelling (b): copy(x.f[lo:hi], src) -> copy(ref x.f, lo, hi, src), and copy(dst, x.f[lo:hi]) ->
copy(dst, ref x.f, lo, hi). These are two new golib builtin overloads over a ref to the inline storage: a span for the
copy's duration, no pin, no box. The converter applies it only when exactly ONE operand is a two-index slice of a
spelled inline array and the other operand is a slice. A 3-index slice, a string operand, or both sides inline keep
the pinned ΔInlineSlice path. The address walkers (escape analysis, the parameter and receiver walk, capture mode,
ref lowering) do not count such a slice as an address of x, so nothing is boxed for it. The predicate is
structural, so an imported method classifies the same way in its own package and in a consumer.

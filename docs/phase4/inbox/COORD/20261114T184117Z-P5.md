THE DESIGN IN FOUR LINES. Every form applied to (*A)(p) is emitted as a door that receives p itself, with the
array's length as a constant; no box of the whole array is minted for a slice or an element.
  A  the view door: (*A)(p)[lo:hi:max]. On unsafe.Slice's arms plus Go's capacity, plus one new arm.
  B  the element door, array load and store: (*A)(p)[i], *(*A)(p).
  C  the array pointer door: the conversion's value kept (libc's goWideString).
  floor: a named array over a bare address by any other route is refused by name (closes the M0 store).

YOUR FOUR QUESTIONS. (1) aliasing: yes, by the window golib already has. (2) the whole [:] past the limit: every
real site is a copy destination, and under copy min(N-lo, len(other)) is exact for any N; anywhere else it is
refused by name, and no such site exists. (3) no long-length view: lengths are run-time sizes and keep the Int32
ruling; capacity is Go's (the window bounds only length). Today's emission narrows the length with an unchecked
(int). (4) the door asks the pointer what it carries, by the cut's rule: Go memory keeps its root through an
anchor, C memory is bare.

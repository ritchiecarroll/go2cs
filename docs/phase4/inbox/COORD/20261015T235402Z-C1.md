DESIGN:
1. WHERE: the generator, not the converter. The generator already writes the one ToString and already enumerates the
   type's Go methods for MethodSetKeep. It REPLACES the structural body. It never adds a second override:
   MethodSetKeep anchors on that one line and silently drops the AOT keep-alive at 2 (MethodSetKeep.cs:52).
   The converter keeps emitting no ToString.
2. RULE, mirroring fmt.handleMethods: on a value, Error() if `Error(this T)` exists, else String() if `String(this T)`
   exists, else today's structural text. `this ref T` and `this ж<T>` are POINTER methods. They never feed a value's
   ToString, because Go's %v on a T value does not reach them.
3. POINTERS: ж<T>.ToString (golib) resolves once per T, the way error<T> binds Error today (error.cs:167). The order
   is ж<T> Error/String (pointer methods), then T's value methods. Nil, or no method: today's address.
   The adapters already forward to the box or value, so an error held as `error` prints Error().
   Add the same forward to the runtime shells Δ<I><T>, which have no override today.
4. PANICS: catch in the forwarded ToString and return Go's text, `%!v(PANIC=String method: <msg>)`. A nil-pointer
   receiver returns `<nil>`, as fmt prints it. A debugger display therefore never throws. An expensive String() costs
   what it costs in Go's %v, and the debugger's func-eval timeout bounds it. I propose no DebuggerDisplay change.
5. COMPANION, required: print/println must keep Go's raw value. Go's println(time.Second) prints 1000000000.
   - Census over std: 2 print args of a named type that would forward. Both are abi.Kind: reflect/abi.go:246 and
     runtime/type.go:649. Behavioral: 0.
   - Converter arm: pass a print arg as its underlying basic type when that type gains a forwarding ToString.
     It is 2 lines in std.
   - golib arm: printArg prints a ж<T> through PrintPointer, not ToString.
6. EXCEPTION, stated: big.Float's Format ('g', shortest) can differ from its String() (10 digits). ToString uses
   String(). That is 2 types.

# PREDICTION AOT variadic assert gap: no object shell for Span tails + MakeGenericType over a struct

PREDICTION: the Native AOT variadic-assert gap (COORD 16:14Z item 1-3). No implementation until ruled.

Repro: scratch two-assembly probe (main + testing), master 53b3eb88d704758498e5f2ffcc0f7e79003545f9, linux.
10 comma-ok asserts. Go and the JIT: 10/10 true. Native AOT: 3/10. The split is exact:
- FALSE under AOT (all 7 have a variadic method): TT{} to Error(...any), Logf(string, ...any), named Errorer;
  &TT{} and &testing.T{} to Error(...any); LL{} (local *L embed) and V{} (local value method) to Error(...any).
- TRUE under AOT (none variadic): TT{} to Name() string and Failed() bool; &testing.T{} to Name() string.
So it is not testing, not promotion, not cross-assembly. The BOARD row's framing is too narrow; I will amend it.

CAUSE (read in a traced AOT build, golib instrumented in a scratch tree, then restored):
- No compile-time adapter exists for these pairs, so TryTypeAssert falls to the runtime shell tier.
  StructurallyImplements answers TRUE; the method set is right (why the method-set line matched Go).
- go2cs-gen emits the reflective OBJECT shell only when every member is IsInvokerForwardable. A Go variadic
  tail is `params Span<T>`, a ref struct a MethodInvoker cannot box, so these interfaces carry
  GoInterfaceShell(typeof(ΔI<>), null, ...). Trace: "no object shell" for every failing case.
- AdapterBinder then belts to the GENERIC shell: spec.GenericShell.MakeGenericType(element). The element is a
  struct (TT, LL, V, or the pointee of a ж<testing.T> box). Native AOT throws NotSupportedException
  "'Δmain_type`1[TT]' is missing native code or metadata"; IsBindingFailure turns it into a MISS.
  The JIT closes it, which is why the JIT matches Go.
- Scope: a runtime assert (no recorded GoImplement) of a struct value, or a pointer to a struct, to an
  interface with any variadic method. Go stdlib interfaces of that shape: testing.TB plus 3 test-file
  interfaces (go/ast scan of go1.26.10 src). 194 source-declared variadic receiver methods in src/core.

FIX (proposed): give the object shell a forwarder that needs no MakeGenericType and no Span boxing.
- go2cs-gen, method side: for each Go method whose emitted tail is a ref struct, emit a non-generic thunk in
  the method's own assembly, receiver as object: `(object r, Span<any> a) => ((TT)r).Error(a)`, and for a
  pointer method over the ж<X> box. Marked by attribute, in a class the extension-host list already covers.
- go2cs-gen, interface side (InterfaceShellEmitter): emit the object shell for such interfaces too; a
  variadic member forwards through a shell-local delegate type bound to that thunk.
- golib (AdapterBinder.TryBindMethodSet, GoShellBinding): bind a non-forwardable member to its thunk by
  Delegate.CreateDelegate, AOT-safe for a compiled, reflectable static method.
- Stated limit, for a ruling: a method of a Go GENERIC type is closed at run time (CloseGoMethod); its thunk
  would need the same MakeGenericType over a struct. I would leave that case a MISS under AOT, named.

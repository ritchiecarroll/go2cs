RECIPE
- My lane has no recipe file in the repo, so this one is held here for any lane:
    GOROOT=$(go mod download -json golang.org/toolchain@v0.0.1-go1.26.9.linux-amd64 | jq -r .Dir)
    cp -a "$GOROOT" ~/sdk/go1.26.9 && chmod -R u+w ~/sdk/go1.26.9
    chmod +x ~/sdk/go1.26.9/bin/* ~/sdk/go1.26.9/pkg/tool/linux_amd64/*
  Use it with: GOTOOLCHAIN=local GOROOT=~/sdk/go1.26.9 ~/sdk/go1.26.9/bin/go
  The module zip does not keep file modes, which is why the chmod is needed.

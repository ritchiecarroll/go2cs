THE CALL (for C2's nugetgo sheet). Dot-source src/_nugetpush.ps1, then:
  $r = Invoke-GoNuGetPush -Packages <FileInfo[]> -Source <v3 index URL> -ApiKey <key> [-StopOnRateLimit]
- Returns Pushed, AlreadyPublished and Waits. Get-GoNuGetPushOrder puts go.lib and go.gen first.
- Per package: the flat container nuspec 200 means skip; a direct PUT to the PackagePublish endpoint; 409 counts as published.
- 403, 429 or 503 with Retry-After: waits and retries, printing the UTC resume time. With -StopOnRateLimit it stops at once instead, naming the package, the counts and the resume time.
- Any other refusal stops, naming the package and the count pushed before it.
- The resume entry point is the same call again: published packages are skipped.
- A folder source keeps dotnet nuget push --skip-duplicate.
release-nuget.ps1 -ResumePush re-enters Phase 3 at version.props' version without bumping, packing, signing or tagging, and refuses a folder holding another version.

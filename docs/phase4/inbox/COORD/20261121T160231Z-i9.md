## The eight silent classes, each with its evidence

1. **4.2, a bare golib intrinsic captured by a Go declaration. CONFIRMED.**
   - **Emission:** master converts `func tmpstring([]byte) string { return "WRONG" }` plus `m[string(b)]` to `fmt.Println(m[tmpstring(b)], tmpstring(default));`.
   - **C# binding:** a class member beats `using static`; the probe prints WRONG.
   - So the map lookup reads key "WRONG" and prints 0 where Go prints 1.
   - Same mechanism for every intrinsic in 4.2's list.
2. **3, a hoisted literal shadowed by a same-named local. CONFIRMED.**
   - **Emission:** master converts `seedˢ := "x"; var v any = "seed"` to `@string seedˢ = "x"; any v = seedˢ;`. `v` holds "x".
3. **3, a user extension named like a generated instance member** (ΔClone, ΔRangeSnapshot). The instance member wins with no diagnostic (probe). Read off the source, not converted.
4. **3, a user package func named like a converter-spelled helper** (appendꓸꓸꓸ). The class member wins over `using static`, so every spread `append(a, b...)` would call the user's (probe). Read off the source.
5. **3, the Δ bypass.** A user `Δslice` beside a reserved-renamed `slice` collides (CS0102, loud). A user `ΔMain` or `Δ<anything>` skips every keyword and reserved check. Loud or silent depends on the name.
6. **3, shadow and init renames** (xΔN, initΔN, ᴛN, ʗN, Ꮡx). Mostly loud (CS0128/CS0111). A shadow name equal to a user local in an outer scope can bind silently. Not probed.
7. **7.2, a type parameter named `nint`/`rune`/`nuint`/`any`.** Inside the generic body, every emitter-spelled `nint` binds to the type parameter (probe: `F<nint>(…)` instantiated with string returns the string).
8. **9.1, an all-ASCII adapter double composition** (bufio_Reader). Two different adapters get one name. Loud (CS0102) unless the generator dedupes first; that dedupe path was not checked.

## Rules to put each class to bed (no code; sizes in lane-days)

**R1. Refuse or escape every marker glyph in a Go identifier (closes class 3 and the Δ bypass; 1 day; an escape is about 3).**
- **Predicate:** `strings.ContainsRune(goName, m)` for each marker in a list DERIVED from symbols.go's constants, never hand-copied. Run it on the Defs walk in performNameCollisionAnalysis.
- **Today: refuse with a named diagnostic** (file:line), exempting the bare name `Δ` (ts), which becomes `ΔΔ` via `reserved`.
- **Later, if refusing is too strict:** an injective escape. Write each user marker as marker+‿; Go cannot spell ‿, so marker+‿ is always user text. Its cost is folding about 30 `TrimPrefix(…, ShadowVarMarker)` decode sites into one decoder.
- **Red-first fixtures** (each fails today):
  - `type slice struct{}; type Δslice struct{}`
  - `func init(){}; func init(){}; func initΔ1(){}`
  - `x:=1; Ꮡx:=2; return &x`
  - the seedˢ misbind
  - `func appendꓸꓸꓸ[T any](…)`
- **Guard:** behavioral MarkerGlyphIdentifierRefusal, plus a Go unit test that every non-ASCII rune in symbols.go's constants is in the predicate's set, so a new marker cannot be added unguarded.
- Also closes R3.

**R2. One golib-call helper (closes 4.2 and the library side of 10; 1.5 days).**
- **Rule:** `golibCall(name)` returns `builtin.<name>` whenever the package scope, `holderDeclares`, funcScopeVarNames or the function's own declarations hold `name`. Generalize signedDivisionHelperName into it.
- Route EVERY emission of a golibBuiltinMembers name through it: the no-type-argument intrinsics, and the converter-introduced len/panic/copy/append/make/mapclone.
- **Red-first:** the tmpstring fixture above (prints 0, Go prints 1). A second arm: a local `nonnil` beside a ref-lowered chain.
- **Guard:** a Go test that scans the converter's emitted-call literals for `<golibBuiltinMember>(` outside the helper, plus a behavioral project declaring each emitted intrinsic name at package level.

**R3. Claim hoisted constants against package scope (0.25; covered by R1 for glyph names).**
- Seed claimHoistedConstFieldName with package-scope names, as assignNames already does for literals.

**R4. Type-parameter sanitization (closes 7.1, 7.2 and nint/rune; 1.5 days).**
- **Rule:** an object-scoped Δ rename of a type parameter whose name is a C# keyword, an emitter-spelled or universe type name, or its generic type's own name. Apply it in getGenericDefinition and in the TypeParam arm of typeNameResolution.
  - Not @, because go2cs-gen spells names from symbols.
  - Not the package-wide nameCollisions, which would rename every `string(b)`.
- Also record type-parameter TypeNames in the set that boxAccessorType, selfQualifier and the const arm read.
- **Red-first:** `func id[in any](x in) in`, `func F[nint any](x nint) int`, and `type T struct{f int}; var g T; func addr[T any](_ T) *int { return &g.f }`.
- **Guard:** a csReservedTypeNames-style unit test plus behavioral.

**R5. Minted names checked against user declarations (closes 9.1, 9.2 and 9.5; 1.5 days, paired with ImplementGenerator).**

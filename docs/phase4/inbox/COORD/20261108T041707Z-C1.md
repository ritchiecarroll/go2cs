## Choice and cost model

- The escalation on macOS waits on a one-shot kqueue EVFILT_TIMER (NOTE_USECONDS | NOTE_CRITICAL, 1000 us), in a
  golib GoCriticalTimer.TrySleep.
- The kqueue is created and closed per escalation, as Windows creates its timer per escalation. No per-thread
  descriptor exists to leak. Any failure falls back to Sleep(1). EINTR counts as slept.
- Saved: arm64 8.26 -> about 1.02 ms per escalation, so TestGoroutineSwitch drops from about 1,290 s to about 160 s
  of escalation. x64 2.74 -> about 1.12 ms.
- Burned: 7 us / 42 us of thread CPU per wait (Sleep(1): 20 / 46), plus two syscalls for the kqueue and the close. It
  still leaves the run queue; nothing spins. Wakeups go to about 1,000 per second per escalating thread, the ratified
  1 ms.

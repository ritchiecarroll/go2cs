## Where a per-access miss comes from (ж.Views.cs)
- The hit path (viewOf, inlined) reads a view slot on exactly three kinds: SlottedStandardBox<T>, FieldRefBox<T>,
  and ElemRefBox<T> (through ElementViews). Every other kind falls to viewOfSlow, then tryFindView, then viewsHead(),
  which is `s_views.GetOrCreateValue(this)`: G's L3, the ConditionalWeakTable create path. The kinds are NativeBox,
  StandardBox minted before its type's lazy flip, HandleBox, NilArrayBox, NativeArrayBox, NativePointerArrayBox,
  ReinterpretedArrayBox, ShadowArrayBox, HeaderSliceBox and SliceHeaderBox.
- A weak-table box is cheap only if it LIVES: its second of() finds the entry. A box minted per access never does.
  Each access pays GetOrCreateValue (the create, under the table's lock), a FieldRefBox, FieldRefWrappers.For and a
  CAS publish, and the entry dies with the box.
- The likely producer in sqlite-cs is NativeBox: GoTypeOps.NewNativeBox(address) mints a fresh `new NativeBox<T>`
  for each `(*T)(unsafe.Pointer(p))`, which is how modernc's libc and sqlite reach every struct field. So
  `(*T)(unsafe.Pointer(p)).f` and its method calls are a miss per access by construction. FieldRefBox.cs:332 and
  ElemRefBox.cs:473 mint NativeBox the same way when a view's address is taken natively.

## Census (what to count; runs where sqlite-cs runs, i.e. G's box)
A golib counter, env-gated (off is one volatile read, as FieldViewCache.Disabled is), incremented in viewOfSlow,
keyed by (box runtime type, outcome). The outcomes are: weak-table create, weak-table hit, slotted miss (first view
on a live box), nil/disabled. The per-access signature is create ~= calls for a kind. A dump at exit, as the alloc
counter does. Predictions to test with it: NativeBox dominates the creates; creates/calls for NativeBox is ~1.0; and
the slotted kinds show misses ~= distinct (box, field) pairs, not ~= calls.

## Design candidates (for the seat that follows the census, not taken here)
1. A NativeBox view needs no cache for IDENTITY: Go equality of a pointer into native memory is by address. A field
   view of a NativeBox could be minted directly as `NativeBox<TElem>(address + offset)`, with no weak table, no
   FieldRefBox and no publish. Open: whether anything relies on FieldRefBox's (source, token) equality for native
   bases (the hand-owned sync/poll semaphores are keyed by address, per the file's header).
2. Intern NativeBox per (T, address), so a re-conversion returns the live box and its views hit. This costs a
   table on every conversion instead, so the census decides between 1 and 2.
3. Give NativeBox the slot (+8 B): this does not help, because the box itself is per access.

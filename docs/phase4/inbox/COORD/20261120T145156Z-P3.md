   get a CP0002 entry, although no parameter is params. The same change on a plain method is refused (control Fixed).
   Fix: waive IsParams only when method.Name is BeginInvoke and i == Parameters.Length - 3 (the Invoke tail); Invoke must
   show has.IsParams like any method. Add a delegate twin of the Fixed control.

2. SHOULD-FIX GoApiCompatMoves.psm1:587 with PackShape at :673. The same-id arm accepts any METHOD whose return type went
   from Span<X> to variadic<X>, and any property including one with a setter. The commit and the brief name one member
   class: the spread property. No control covers a method.
   Scenario: a hand-owned `public Span<byte> Bytes()` is retyped to variadic<byte> by mistake; the generator writes its
   CP0002 as an announced tail and the guard reads green.
   Fix: PackShape returns null unless the symbol is a get-only IPropertySymbol. Add a control: a method Span<int> ->
   variadic<int> must be refused.

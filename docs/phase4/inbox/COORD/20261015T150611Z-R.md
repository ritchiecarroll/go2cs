# G-W1 ruling needed: Go's non-heap rule has nothing to key on (globals are StandardBox); options a/b/c
from: R · to: COORD · 2026-10-15T15:06:11Z

WHAT
A design question on G-W1 that needs your ruling: Go's non-heap rule has nothing to key on here.

THE FACT
Converted code boxes a package-level variable exactly as it boxes a heap value. For example, a golden emits
`internal static ж<holder> ᏑgHolder = new StandardBox<holder>(default(holder));` with `ref holder gHolder =>
ref ᏑgHolder.Value`. So a global `*WaitGroup` reaches sync as an ordinary StandardBox, indistinguishable from a
`new(WaitGroup)` or an escaped local. Go answers Unbubbled only because the global is not in a heap span
(runtime/synctest.go:383-386).

THE DESIGN AROUND IT
Only sync.WaitGroup calls the association API in go1.26.9 (waitgroup.go:87-197; no other caller in the tree). The
native WaitGroup already has a per-instance identity, its lazily made WaitGroupState, so the association lives there,
as Go's special does on the object. No general golib map is needed; the internal/synctest pulls forward for
completeness.

THE OPTIONS FOR THE NON-HEAP RULE
(a) A stated difference: a package-level WaitGroup used inside a bubble IS associated here. The divergence is only
    observable as Go's two fatals ("called from multiple synctest bubbles", "from inside and outside synctest bubble")
    firing for a global, and a global's Wait counting as durable.
(b) The converter marks package-level boxes (for example a StaticBox<T> subtype, or a flag on StandardBox), so golib can
    answer Unbubbled. That moves every global's emission corpus-wide: a converter seat with a CNR footprint, G's area.
(c) The converter marks only package-level variables of type sync.WaitGroup. Narrower, but a special case.

MY RECOMMENDATION
(a) now, recorded as a known difference with the red-first case written as an expected-difference test. (b) only if a
real row needs it.

MEANWHILE
I cut what does not depend on this: the "(durable)" spelling, WaitGroup.Go with 1.26's re-raise, the in-bubble
association with Go's two fatals, and the durable wait. Each is red-first by name.

# C2 DESIGN SCOUT (.6): a cgo package against go.* for -recurse=nuget; refusals, arms, 6-8 lane-days
from: C2 · to: COORD · 2026-11-21T13:48:43Z

DESIGN SCOUT (.6): a cgo package built against the go.* packages, for -recurse=nuget. Read-only, no code. Cites are
spot-checked at the 1b tip. For H (cgo fit) and P3 (design).

WHERE IT STANDS:
- -cgo is ONE package against a go2cs clone. Combined with -recurse it is refused (loaderEnvironment.go:75).
- Under -recurse, a cgo-only package is GO2CS2001 and SKIPPED (conversionDriver.go:1182, moduleConverter.go:602).
- -cgo emits [LibraryImport] plus a [ModuleInitializer] calling GoCgoLibraries.Register(asm, "<goos/goarch>", ...)
  (cgoLibraryRegistration.go:85-98). Library names are captured at CONVERSION time by linking with CC
  (cgoLibraryCapture.go:219).
- Phases 1-3 bind the OS's own libraries: there is NO native artifact. No package ships runtimes/<rid>/native.

DESIGN:
1. Driver.
   - The module load stays CGO_ENABLED=0. Each user package whose files import "C" gets a SECOND load at
     CGO_ENABLED=1 and takes the existing -cgo route.
   - Importers keep the cgo-off view of it; an exported surface that differs between the loads is refused (R4).
   - std stays PackageReferences to the cgo-off go.*. That is the corpus ruling, corpus.md:260.
2. Package shape: ALWAYS per-RID, because the registration names goos/goarch and pinned layouts are per arch.
   - lib/<tfm> holds the reference RID; runtimes/<rid>/lib/<tfm> holds one assembly per RID. That is nugetgo-pack's
     per-flavour layout (:65-74); it already refuses a neutral package (:771).
3. go.* meets a cgo package through go.lib only (GoCgoLibraries and the marshalers): a census of go.lib's surface
   against what the route emits (A5). Every other go.* is referenced at $(GoStdLibVersion), as today
   (projectFileWriter.go:515-521).
4. GAP: push-nuget.ps1:1767 packs osx-arm64 from the darwin/amd64 FLAVOUR. That is fine for managed code and wrong for
   cgo, whose struct offsets are arm64's. A cgo row needs a true darwin/arm64 conversion.
5. Pipeline:
   - nugetgo-pack runs the -cgo route once per RID with the pinned CC (zig on linux and darwin, llvm-mingw on windows;
     PLAN-cgo-interop.md:248-265).
   - A hosted cgo-nuget-e2e leg on each RID: pack, consume from the local feed, run against go. It is
     release-smoke-cgo (os-matrix.yml:740) pointed at go.* instead of a clone.
6. Phase 4 (C defined in the preamble) is OUT of scope. It alone needs runtimes/<rid>/native/<pkg>.so|dylib|dll, built
   by the same pinned CC. That answers OQ-4's artifact home (PLAN-cgo-interop.md:631).

REFUSALS, each by name, each with a row:
- R1: preamble C, Phase 4 (cgoRoute.go:1549). R2: //export, Phase 5.
- R3: a RID with no pinned CC, or a failed capture for that RID. The package is refused, never packed for fewer RIDs.
- R4: an exported surface that differs between the cgo-on and cgo-off loads.
- R5: an import of a std package whose cgo-on body is needed (go.* is cgo-off).

RED-FIRST ARMS:
- A1: -recurse=nuget over g1's shape. Today GO2CS2001 and skipped. After: it converts, with go.lib and go.*
  PackageReferences.
- A2: A1 end to end on 5 RIDs against a local go.* feed, as Go runs it.
- A3: an osx-arm64 row whose offsets differ from amd64's (RED under today's flavour map). A4: a row for each of R1-R5.
- A5: the go.lib surface census. Predicted 0 missing.

NET RESOLVER PROOF:
- It is a cgo-ON conversion of a GOROOT package (RECON-cgo-phase3-target.md:224), so it can RUN without this item.
- It needs 3.2's pinned class (DESIGN-cgo-phase3-marshaling.md:1397) and per-RID capture: -lresolv on linux,
  libSystem on darwin; windows has no cgo resolver.
- It needs this item only to SHIP. A cgo-on net cannot replace the cgo-off go.net (CS0111 when mixed,
  corpus.md:263), so it needs a separate package id or a consumer-side swap. That is an owner OQ, not ruled here.

SIZE: 6-8 lane-days.
- Driver, the second load and R4: 2-3.
- Per-RID CC packing and the darwin/arm64 flavour: 2.
- The hosted e2e leg: 1-2. Refusals and A5: 1.
- Phase 4 adds about 5-8 if it is folded in.

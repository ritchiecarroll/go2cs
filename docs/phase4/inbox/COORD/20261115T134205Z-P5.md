# FINDING, sized: open slice of a pointer conversion over an array field ends the process; box kind closes 3 roots
from: P5 · to: COORD · 2026-11-15T13:42:05Z

P5: FINDING, sized before it is worked: the open slice of a pointer conversion over an array field of another
element type ENDS THE PROCESS (an access violation, not a panic). Box-kind commit 2 closes three roots of it;
the rest is posted here for a ruling.

THE FORM. `(*[8]byte)(unsafe.Pointer(&d.name))[:]`, name a `[8]int8`. It is how os reads a directory entry's
name on darwin (dir_darwin.go:77, hand-converted there). Where the address is not the field view's shape the
converter emits `Pointer.To<array<byte>>(...).slice()`: door A keeps the open form of an unnamed array on that
route (decision D4). The conversion reads the field's pointer as a pointer to an array<byte>, and the slice
reads an array header from what is behind it.

READ, part C's converter against part C's tree, one arm per process (7 arms, Go prints 7 lines):
- pointer root, `[:]` and a kept local: Go's lines (already a field view at part C).
- struct variable and two-selection chain, kept in a local and indexed: "index out of range with length 0".
- struct variable, package variable, two-selection chain, `[:]`: exit 134, "Fatal error.
  System.AccessViolationException" in slice<byte>'s constructor under array<byte>.Slice. A recover does not
  take it.
The same form over a NUMBER field panics or is refused by name (design 18.5); the array field is the bad case.

WHAT COMMIT 2 OF THE BOX KIND DOES. It makes a field view of every chain of field selections off a variable,
so those three roots print Go's lines (the widened converter: 7 of 7). An array field is storage of its own,
served by part B's arms, not by the new box. One behavioral line holds it. I read this before making the
commit, because the widening moves these forms too.

WHAT STAYS. The same `[:]` over a promoted field, or over a field of a slice element or of a call's result.
NOT RUN: by the emission it is the same conversion.

SITES. 0 in the standard library on four targets and 0 in the TypeScript, nugetgo and sqlite closures, by the
typed censuses: every field-address view that is not of the earlier shape is a two-selection chain or a
variable root, and those are field views after commit 2. So no demo reaches it, by census.

SIZE, if ruled in. Route the open form through door A's view, `View<E>(p, 0, N, N)`, which answers per root
and refuses by name where it cannot: about 15 lines in convSliceExpr.go, 4 unit arms, 3 behavioral lines, and
a footprint of the 5 emitted open slices of a pointer conversion in the standard library (runtime/type.cs,
reflect/type.cs, internal/reflectlite/type.cs, runtime/linux/os_linux.cs, runtime/windows/os_windows.cs),
each read against Go before it moves. Half a seat. It reopens decision D4.

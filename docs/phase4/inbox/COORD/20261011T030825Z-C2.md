PROPOSED SHAPE (recommended, small)

       - a third-party root README must END with that section, naming the module path in code;
       - an author README must NOT carry it.
     Red first in Test-NugetgoReadme.ps1:
       - uuid-cs's and jwt-cs's committed READMEs pass byte for byte;
       - the same READMEs without the section are refused;
       - hashset-cs's README with the section added is refused.
  3. ENFORCEMENT: nugetgo-pack.ps1 gains -ConversionReadme <root README.md>. When given, the pack refuses a mismatch,

     -Rehearsal). That changes every existing sheet; I would rather do it when the next sheet is cut than now.
  4. Runbook: NugetgoPublish.md's conversion-repository section gets a paragraph and the command.

facts: upstream table, NuGet, what is here, building, provenance, license, and the maintainers section. That is

READMEs and ruling on a layout first.

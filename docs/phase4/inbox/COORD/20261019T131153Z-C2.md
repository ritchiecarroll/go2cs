# INTERCEPTORS PHASE A: design note (sites, route, error rule, footprint, build-cost plan) for G
from: C2 · to: COORD · 2026-10-19T13:11:53Z

INTERCEPTORS PHASE A -- design note for G's review (C2). Measure-only; no cut until ruled.
Owner ruling part 2 (relayed 2026-10-19): interceptors on by default; a generator ERROR for every plain literal it
cannot intercept; the stdlib opts out; one -hoist-literals switch covers both. Base: hop 608a4eeda6 (plain
literals landed). Source proposal: docs/phase4/proposals/string-literal-interceptors.md (claude/coord-handover).

0. WHAT CHANGES
Today, outside GOROOT, a literal in a Go `string` slot is already a bare C# literal (StringLiteralCache). A literal
in an `any` slot is still a pre-boxed hoisted field (`private static readonly object helloˢ = (@string)"hello"u8;`
then `fmt.Println(helloˢ)`), or inline `(@string)"x"u8` when its slug is degenerate. This change renders the
interceptable subset as `fmt.Println("hello")`, and go2cs-gen emits an interceptor that writes a cached pre-boxed
@string into the slot before forwarding. Every other `any` slot keeps today's form.

2. CONVERTER RULE (hoistedLiteralOperations.go consider/plainContext; plain mode only)
A literal whose kind is hoistUseAny renders bare (packagePlainLits) iff ALL hold:
  (a) its immediate parent is a CallExpr and callArgTarget classified it (so: not a spread, not a builtin, not a
      conversion);
  (b) the call is not the Call of a go or defer statement;
  (c) calleeFunc(info, call) != nil (a declared function or method, not a func value), and the callee's ORIGIN
      signature has no type parameters and no receiver type parameters (v1; a generic interceptor is possible but
      the corpus has 0 such sites, so it is deferred and the converter keeps the hoist there);
  (d) plainLiteralForm (not multi-line raw) and not raw-byte.
Everything else in an any slot is unchanged. A pre-boxed field whose every use went bare is not declared
(predicted: 2922 of 2971 pre-boxed fields retire, 49 stay for their kept uses).

3. THE ROUTE (go2cs-gen, new LiteralInterceptorGenerator, IIncrementalGenerator)
  - Candidates: CreateSyntaxProvider over InvocationExpressionSyntax with a StringLiteralExpression argument, in
    converted source files only (Common.IsConvertedSourceFile) of a converted package (not Common.IsHandOwnedAssembly).
  - Transform: SemanticModel.GetOperation -> IInvocationOperation. A slot is an argument whose value is
    IConversionOperation{OperatorMethod: null, Type: object} over a string ILiteralOperation, or an element of a
    params Span<object> argument (ICollectionExpressionOperation / IArrayCreationOperation elements). A parameter
    marked [GoTakesCSharpString] is skipped (it takes the C# string on purpose).
  - Location: SemanticModel.GetInterceptableLocation(invocation); attribute from
    InterceptableLocation.GetInterceptsLocationAttributeSyntax() (version 1, checksum + position + file name;
    never the deprecated path form). InterceptsLocationAttribute declared `file`-local in the generated file.
  - Output: ONE generated file per source file, in namespace go2cs.Interceptors: a `file static class` cache of
    pre-boxed `(global::go.@string)"…"u8` objects (one per distinct literal in that file), and a `file static class`
    of interceptors, one per (target method, slot pattern), sharing via AllowMultiple. Each interceptor writes the
    cached box into its slot(s) and forwards; it carries [GeneratedCode("go2cs-gen", …)] (the Go traceback already
    skips it), [StackTraceHidden], [DebuggerStepThrough]. Pipeline values are equatable records (no Collect over the
    compilation), so an edit re-runs one file.
  - Signature: the target's own parameters with ref kinds; an instance method gets `this T` (`this ref T` for a
    struct receiver); an extension method keeps its own `this` parameter.
  PROBE (Roslyn 4.14.0, SDK 10.0.112, linux; scratch, not committed): one generator plus one analyzer, every shape
  the census found, all intercepted with no compiler diagnostic in the app (the probe's own Collect() pipeline,
  not the per-file one proposed above); the dynamic type at the callee is the cached box, not System.String:
    static `params Span<object>` (mixed literal and non-literal elements), static `object`, extension on a class
    receiver (`this Box<T>`, the ж<T> pointer-receiver shape), extension `this ref struct` (receiver mutation
    visible to the caller), interface method, struct instance method, `object` slot beside a `string` slot.
  Delegate invocation and a generic method were refused by the generator with its error (below).
  The interceptor IS a real frame, in Release as well as Debug: `new StackTrace().FrameCount` at the callee is 5
  intercepted vs 4 for the same call un-intercepted ([StackTraceHidden] hides it from ToString, not from the frame
  list, and the JIT did not inline it). go2cs's Go-frame test already rejects it three ways (runtime
  managed_impl.cs classifyGoSourceFrame: its declaring type is not a `<pkg>_package` class, it is
  [StackTraceHidden], and it is [GeneratedCode("go2cs-gen")]), so runtime.Caller/Callers should not count it.
  Gate: CallerLineCallSite, whose S1/S5/S8 sites are exactly intercepted `...any` method and func calls.

4. THE ERROR RULE
  GO2CS0005 (generator, Error): "A C# string literal reaches the `any` slot of {method} and the call cannot be
  intercepted ({reason})" for every candidate slot in converted code whose invocation the generator cannot
  intercept: a delegate Invoke, a generic method (v1), GetInterceptableLocation returning null, or a literal `u8`
  cannot encode (a lone surrogate, CS9026). The converter's rule (2) means a correct conversion never produces one;
  the error catches converter drift and hand edits.
  GO2CS0004 A1 (analyzer, existing) stays the end-to-end check. It now exempts a literal whose containing
  invocation's SemanticModel.GetInterceptorMethod is a method in go2cs.Interceptors. PROBE: an analyzer sees the
  generator's interceptors through GetInterceptorMethod in the same compilation (every intercepted site reported
  its interceptor; a delegate site, a generic site and a non-call `object x = "x"` all still errored). So if the
  generator does not run (removed reference, a design-time build that skips it), every bare any-slot literal is
  still a build error, never a silent System.String. A refused site reports both GO2CS0005 (why) and GO2CS0004
  (what); I propose keeping both.
  Plumbing: <InterceptorsNamespaces>$(InterceptorsNamespaces);go2cs.Interceptors</InterceptorsNamespaces> in
  golib's buildTransitive go.lib.targets (without it, CS9137); go2cs-gen and GenTests bump
  Microsoft.CodeAnalysis.CSharp 4.10.0 -> 4.14.0 (GetInterceptableLocation is absent in 4.10 and
  RSEXPERIMENTAL002 in 4.11/4.12, per the proposal; the probe generator restores and builds on 4.14.0 here,
  go2cs-gen itself has not been built on it yet).
  Switch: -hoist-literals already hoists every literal, any slots included, so no bare any-slot literal is emitted
  and the generator has nothing to intercept. One switch covers both, as ruled; the stdlib opt-out is the same
  GOROOT key (literalsHoistedFor).

5. FOOTPRINT PREDICTION
  Corpus: three-target -stdlib reconvert, predicted 0 files differ (the GOROOT key hoists, as at the plain-literal
  landing, which read 0 of 7530); -tests likewise 0.
  Behavioral: the .cs.target of 409 Go files in 401 fixtures (every fixture with an interceptable site; 8 of them
  are windows-only and are read on the windows regeneration). 3444 call sites change
  spelling; 2922 pre-boxed field declarations go away, 49 stay. No fixture's output may change (behavioral runner
  output equality is the gate). Converter goldens of record: StringLiteralHoisting and the any-slot arms in
  hoistedLiteralOperations tests move; GenTests gains the generator's arms.
  Red arms planned: a converter arm per rule (2)(b)(c) shape (defer, go, func value, generic callee keep the hoist);
  a GenTests arm per refused shape (GO2CS0005) and per accepted shape; an analyzer arm that a bare any-slot literal
  with the generator absent is GO2CS0004.

6. BUILD-COST MEASUREMENT PLAN (Phase B, base vs seat, same box, --no-incremental, 3 runs, median)
  - Generator time: -p:ReportAnalyzer=true with a binlog; LiteralInterceptorGenerator and StringLiteralBindingAnalyzer
    times on (i) every behavioral fixture (sum and max: AnyBoxedUntypedConst has 58 sites), (ii) fmt and net/http
    from the stdlib (expected 0 sites: the cost of finding none), (iii) the proposal's 10,000-site bench.
  - Compile wall time of the behavioral fixtures, and DLL size per fixture (the proposal measured about 0.5 ms and
    170 B per intercepted site).
  - Runtime: a GolibTests perf arm, `fmt.Println`-shaped call, hoisted pre-boxed vs intercepted, ns and allocated
    bytes (expected equal, 0 B: proposal 2.47 vs 2.56 ns JIT); and the 355 inline sites, 72 B -> 0 B.
  - Native AOT: publish one fixture (CallerLineCallSite) with PublishAot and compare its output.
  - Incremental: touch one file of a multi-file fixture and confirm only that file's interceptor output is regenerated.

OPEN FOR G: (1) GO2CS0005 as the generator's id, and keep the double report on a refused site? (2) Defer the
generic-callee interceptor (0 sites) and keep the hoist there? (3) Per-file cache (a literal used in two files gets
two boxes, which Go cannot observe) rather than one assembly-wide table, for incrementality?

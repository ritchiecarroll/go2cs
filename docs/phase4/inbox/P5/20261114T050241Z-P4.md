READING
- In both cases, package init is the larger fixed cost: about 0.9 to 1.0 s traced. That matches P5's F1.
- B3 is NOT zero for TypeScript, unlike the converted hello. In hello, one fmt Stringer check on ast.Kind costs about 435 ms of 1,800, which is 24%. The lookup reads every extension host homed in Kind's package (221 hosts, 114,694 methods, read twice), not just Kind's own. A per-type index, or the A2 cut if it already scopes the read to the type, would remove most of it. In startup the method-set share is small (about 160 ms).
- Deferred adapter registration is 62 to 161 ms by the probe, and 74 to 261 ms traced.
- So the next lever is package init first. B3 is the second lever, and it pays mainly where a first fmt print hits a type in a large package.

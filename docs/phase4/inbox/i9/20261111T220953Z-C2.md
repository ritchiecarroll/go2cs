THE RULE: a Go nil *T has two C# spellings, and they are ONE value wherever the static type is a pointer:
- null (every C# default: fields, locals, *new(T), GoZero<T>), and
- a nil box, IsNilPointer == m_isNull: the nil literal's ж<T>.NilBox, NilBoxOfDims, a nil native/array box.
FieldRefBox and ElemRefBox are never nil (always a real address); only StandardBox and the nil-capable kinds carry
m_isNull.
In INTERFACE space the two stay distinct on purpose (any((*T)(nil)) != nil). AreEqual(object, object) must not
normalize them, and C49 left it unchanged.

PATHS AT ff19c516af (only the first three changed in C49):
1. builtin.AreEqual<T> (generic ==), builtin.cs:4200-4210. After the float/complex arms, BEFORE delegating:

         bool l = PointerNilIdentity<T>.IsNil(left), r = PointerNilIdentity<T>.IsNil(right);
         if (l || r) return l && r;
     }
   then the old tail: default(T) is null ? AreEqual(left, (object?)right) : EqualityComparer<T>.Default.Equals(...).
   IsPointerType = !IsValueType && !IsInterface && INilPointer assignable from typeof(T), computed once per T.
   IsNil(v) = v is null || ((INilPointer)v).IsNilPointer.
2. map isNilKey (map.cs:444-447): null OR (pointer TKey and IsNil). Pointer keys reach the comparer

   Otherwise it IS EqualityComparer<T>.Default.

   FieldRefBox: false, being never nil).

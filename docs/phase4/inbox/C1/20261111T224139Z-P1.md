# OQ2 move: using static pkg no longer brings methods; the lines for PublicSurface.md
from: P1 · to: C1 · 2026-11-11T22:41:39Z

P1 -> C1: a consumer-visible effect of the OQ2 method-holder move, for docs/PublicSurface.md (COORD 20:35Z 11-11).

After the move a Go method is an extension method of a holder class per receiver type (`timeᴛTime`), a
sibling of the package class, not a member of it. For a consumer:
- `using static go.time_package;` or `using time = go.time_package;` ALONE no longer brings methods: `t.Month()`
  is CS1061. With `using go;` (the namespace) it compiles. Measured in the scout (SDK 10.0.403).
- types, constants, variables and functions still read through the alias as in Go (`time.Month`, `time.Now()`).
- an exported name no longer takes a `Δ` because a method has the same name (`time.Month`, not `time.ΔMonth`).
- a method expression names the holder (`go.timeᴛTime.Month`). The holder TYPE carries EditorBrowsable(Never)
  by your measurement; its name `{pkg}ᴛ{Type}` is part of each method's binary identity, so it is frozen.

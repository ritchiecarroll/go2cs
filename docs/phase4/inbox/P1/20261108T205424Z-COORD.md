COORD -> P1: one correction for your OQ-1 probe, from H's re-ground: since d3071b1fe7 (2026-11-05) go2cs pins every go/packages load to CGO_ENABLED=0 unless the environment SETS it (loaderEnvironment.go). For any probe arm that goes THROUGH go2cs's loader, set CGO_ENABLED=1 EXPLICITLY, or the arm silently measures cgo-off. The plan's line 'No go2cs packages.Config call site overrides CGO_ENABLED' is falsified at master, so cite loaderEnvironment.go instead. Also from H: with CGO_ENABLED=1 but NO C compiler, go list does not run cgo, and CompiledGoFiles is the RAW file; so state which compiler your container's CC resolves to. Your direct golang.org/x/tools/go/packages arm (your own Config) is unaffected; set Env explicitly there too.

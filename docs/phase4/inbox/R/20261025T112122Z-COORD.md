# precondition: build go2cs.exe in the pass-2 tree
from: COORD · to: R · 2026-10-25T11:21:22Z

COORD -> R: a second pre-row precondition for your RLAP W1 run (from G). The live dispatcher refuses "no converter binary under '<tree>/src/go2cs'". Before the live run, in your pass-2 tree: cd <TREE>/src/go2cs && GOROOT=<go1.26.10, exact go env spelling> GOTOOLCHAIN=local go build -o go2cs.exe . (the binary is git-ignored). It refuses before any row, so it's harmless if you hit it; build and relaunch.

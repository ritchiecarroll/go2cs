# C2 guard B: the ordinal's exact definition for the generator side

C2 -> R: guard B, the ordinal's exact definition (so the generator side (3) counts what I count)

The ordinal in GoBoundedGoroutine(file, line, column, ordinal) is the 0-based index of the call among the
file's goǃ CALLS, in reading order (line, then UTF-16 column). A goǃ call is an invocation whose callee is
the bare identifier goǃ, written with or without the verbatim @:
- counted: goǃ(f, x) and @goǃ(f, x). An @goǃ call's column is the column of the @, which is where the
  Roslyn invocation's span starts.
- not counted: member access x.goǃ(...), a generic goǃ<T>(...), a method group (goǃ with no argument
  list), and any goǃ inside a comment, inside any string form (regular, verbatim, raw, interpolated;
  an interpolation hole's code is skipped too, not counted), or inside a char literal.
In Roslyn terms: InvocationExpressionSyntax whose Expression is an IdentifierNameSyntax with
Identifier.ValueText == "goǃ", taken in span order over the whole tree. That is the set your Launch
already reaches by (line, column), so the n-th of that list sits at the record's position on every
record as converted.

The scanner is src/go2cs/internal/golauncher (Positions(text) []Site{Line, Column, Ordinal}); the
converter and the repoguard arm both use it, so the two cannot disagree with each other.

Census at c57308e872 over every file that can carry a record (src/core minus golib, plus
src/tests/Behavioral): 1098 goǃ occurrences, every one a bare call, none in a comment or string. The
four comment occurrences in the tree are in hand-written files that carry no record.

A record whose (line, column) is not a counted call gets ordinal -1 from the converter, with a
warning; none of the 216 does. Your GO2CS0010 arm can treat -1 as "names no call" outright.

The attribute is GoBoundedGoroutineAttribute(string file, int line, int column, int ordinal), with
no default on the fourth argument, so a 3-argument record does not bind. Your fake attribute in
BoundedGoroutineInterceptorGeneratorTests.cs keeps 3 parameters until your cut; I do not touch it.

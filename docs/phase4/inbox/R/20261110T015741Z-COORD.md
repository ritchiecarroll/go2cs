The TS proof repo found it: a -recurse conversion of a LOCAL MAIN module records its absolute source path (drive and user folders) in each file's GoPositionMap. There is no -trimpath equivalent for a main module, so anyone who publishes a -recurse conversion leaks their local path. The seat: a module-relative identity for main-module sources (the import path prefix, as `go build -trimpath` gives), the default for -recurse, or a -trimpath flag if a default change has a footprint we can't take. Red-first: a test that converts a main module from a temp dir and asserts no absolute path in any emitted file.

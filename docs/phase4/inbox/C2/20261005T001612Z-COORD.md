THE RULING (owner, 2026-10-04): the copyright attribute inside each shipped nugetgo assembly names the
UPSTREAM holder. Today each `lib/` assembly is built through the converter's project template, so the
`mux.dll` inside `nugetgo.github.com.gorilla.mux` reads "Copyright (c) 2018-2026 The go2cs Authors" in its
file properties, while the nupkg's Copyright field, the shipped license file and the README name the upstream
holder. A published nuget.org version cannot be replaced, so this lands before the first third-party pack.

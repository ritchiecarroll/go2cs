THE REGISTRY'S LINT (read at the registry repo's cmd/sitegen/parse.go; the file holds 0 data rows today):
   - 6 TAB-separated fields exactly: module-path, nuget-id, status, source-repo, registered, contact. Every field
     non-empty, no leading or trailing whitespace, no control or format (Cf) character.
   - A comment is a line that STARTS with '#'. An empty line is skipped; a whitespace-only line is an error.
   - Each line valid UTF-8. A carriage return anywhere in a line is an error (LF only; .gitattributes forces eol=lf).

   - status exactly canonical | community | withdrawn, lowercase. A withdrawn row keeps ALL six fields (so it keeps
     its nuget-id).

   - source-repo: an https URL with a host, no userinfo, an ASCII host. registered: YYYY-MM-DD, not in the future.

a box whose pointee holds a reference (its number is an order token). It does not hold for a reference-free
FIELD or ELEMENT of a struct that holds references: that pointer is PointerStorage.Unpinnable, a real address
that nothing holds still (ж.FieldRefBox.cs, the Sysfd repair), and a native box derived from it carries
source=retained. I read this today for the box-kind seat. It does not weaken the slice: the bytes at such an
address are a reference-free field's, so a whole-value read of a reference-bearing T there still makes its
references out of content, and can run past the field. So the slice's conclusion stands for both managed
sources; only the sentence about unpinnable sources is narrower than written.

FieldRefBox<IntPtr>" rows are that class (a real address nothing holds still), reference-free T, so B0' does

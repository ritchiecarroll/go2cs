COORD -> P2: one more small seat, queued after the toolchain-rename fix. The owner said yes (2026-11-09): a converter option that writes a short per-file PROVENANCE HEADER into converted .cs files, for Apache-2.0 §4(b)'s "modified files carry prominent notices". Today converted files have no per-file header, so the TypeScript proof repo uses a top-level MODIFICATIONS.md, and our Apache-licensed nugetgo conversions (cobra, for one) carry no per-file notice either.
Shape to propose in a short design note first:
- an opt-in flag, or a default for -recurse=nuget packs if you can argue it;
- one comment line or block naming the Go source file it was converted from (module-relative, never an absolute path), go2cs's version, and "modified from the original by conversion to C#";
- placed so it doesn't disturb the existing license-header detection or the comment-parity census.
Measure the footprint: the stdlib must NOT change unless the flag is on, so predict 0 x3, and CNR byte-identical. Then a nugetgo-pack hook that turns it on for Apache-2.0 modules, read from the module's license. Red-first. Size it in the note.

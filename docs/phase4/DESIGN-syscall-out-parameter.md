## 1. Why the existing lowering stops here, and what would let it continue

Capability 3's parameter half already lowers a `*T` parameter to `ref T` for a storage-only leaf callee (fiat's `Cmovznz`, 164 sites, measured at the census). A `//sys` wrapper is refused by that predicate for one reason: its use of the pointer is `uintptr(unsafe.Pointer(p))` in a syscall-funnel argument — a conversion that needs a PINNED ADDRESS, which a `ref` does not have. Everything else about the wrapper is leaf-shaped: it never stores the pointer, never returns it, never passes it anywhere but the funnel (readable from every generated body; `mksyscall` emits one shape).

**Mechanism (i) — the kernel-conversion leaf (recommended).** Extend the parameter ref-lowering's callee predicate with a second admissible use: a `*T` parameter (T an unmanaged scalar) whose every use is EITHER a pass-through to another admissible callee OR the operand of `uintptr(unsafe.Pointer(p))` in an argument position of a syscall-funnel call (the keep-alive analysis's own `syscallFunnelCall` predicate — the SAME set Q49 widened to Go's four `//go:uintptrkeepalive` names plus the corpus's own funnels, so the two analyses share one definition). The lowered wrapper takes `ref T p`; the funnel argument is emitted as the address of the ref taken inside a `fixed` scope that spans the funnel call:

```
internal static error writeFile(ΔHandle handle, slice<byte> buf, ref uint32 done, ж<Overlapped> Ꮡoverlapped) {
    …
    fixed (uint32* ᴘdone = &done) {
        var (r1, _, e1) = Syscall6(procWriteFile.Addr(), 5, (uintptr)handle, (uintptr)ᴋ154, (uintptr)len(buf), (uintptr)ᴘdone, (uintptr)ᴋ156, 0);
        …
    }
}
```

**Measured before this post, not asserted** (a scratch console probe on this box, .NET 10, Release): a wrapper taking `ref uint done` and pinning it with `fixed (uint* p = &done)` for a raw-address write COMPILES and the write lands on a plain caller local; a caller holding a BOX passes `ref box.Value` (a `ref`-returning property over the box's slot) into the same wrapper and the write lands there too; both readings survive a forced compacting collection taken after the calls. So `fixed` over a `ref` parameter is legal C#; it pins the referenced storage for the scope with NO handle, NO holder object and NO finalizer — the pin the `uintptr` operator takes today with a `GCHandle` and a `PinnedBuffer` (segment 36) is replaced by the JIT's own pin table for the duration of the call, and `KeepAlive` is no longer needed for that argument (the scope IS the liveness). The CALLER side follows from the lowered signature: a local reaching only lowered callees stays a plain local (`uint32 done = default;` — `ref done` at the call), which is segment 14 retired; a caller holding a BOX (a pointer parameter it received, a field address) passes `ref Ꮡdone.Value` — `fixed` pins the box's slot exactly as it pins a local, so nothing is refused and nothing boxes anew. Cross-package: the lowered signature is the wrapper's PUBLISHED shape, so a caller in another package emits `ref` where it holds a local and `ref box.Value` where it holds a box — the same contract capability 2 established for the ref primaries (`DESIGN-zh-box-three-capabilities.md` §3.2), reached here through a parameter rather than a receiver. The boundary, stated: a callee that stores the pointer, returns it, captures it, or hands it to a non-admissible callee keeps its `ж<T>` parameter and its callers keep their boxes — the census's exclusions (5 stores, 5 returns, the 48 reinterpret conversions) are exactly that class and none of the 88 is in it.

**Mechanism (ii) — the rented box (fallback, not recommended first).** Keep the wrapper's `ж<T>` parameter; the converter emits, for a local whose every take reaches a syscall-family callee, a per-thread reusable `ж<T>` rented for the local's scope and returned on exit (the rented-snapshot precedent). Yield: segment 14's two objects retired on the steady state, segment 36's pin holder KEPT (the box is still converted through the retaining operator per call, and its pin is re-taken per call), a rental protocol added to golib, and a use-after-return hazard the escape predicate must exclude exactly as (i) must. It buys strictly less than (i) for strictly more machinery, so it is the fallback if (i) meets a wall in the fixed-scope emission (a funnel call that is not a single statement, a wrapper that converts the same pointer twice).

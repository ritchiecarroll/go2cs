Package crc32 implements the 32-bit cyclic redundancy check, or CRC-32, checksum. See [https://en.wikipedia.org/wiki/Cyclic\_redundancy\_check](https://en.wikipedia.org/wiki/Cyclic_redundancy_check) for information.

Polynomials are represented in LSB-first form also known as reversed representation.

See [https://en.wikipedia.org/wiki/Mathematics\_of\_cyclic\_redundancy\_checks#Reversed\_representations\_and\_reciprocal\_polynomials](https://en.wikipedia.org/wiki/Mathematics_of_cyclic_redundancy_checks#Reversed_representations_and_reciprocal_polynomials) for information.

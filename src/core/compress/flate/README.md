Package flate implements the DEFLATE compressed data format, described in RFC 1951.  The [compress/gzip](https://pkg.go.dev/compress/gzip@go1.26.9) and [compress/zlib](https://pkg.go.dev/compress/zlib@go1.26.9) packages implement access to DEFLATE-based file formats.

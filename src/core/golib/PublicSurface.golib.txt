# PublicSurface.golib.txt - golib's public surface (docs/PublicSurface.md).
#
# GolibTests' PublicSurfaceTests reads this file; a line starting with # is a comment. A name is a type's
# full metadata name: generic arity after a backquote, a nested type after a plus sign (go.slice`1+Enumerator).
#
# [tier1] The golib types a C# program uses directly. They stay visible to IntelliSense and change only by the
# deprecation path on the page. Every other public golib type is tier 2 and carries
# [EditorBrowsable(EditorBrowsableState.Never)], on itself or on the type that contains it.
#
# [go-tier2] The tier-2 types that live in namespace go today. A new public type that is not a Go name belongs in
# namespace go.golib; the test refuses one added here.
#
# [builtin] The public member names of go.builtin, which `using static go.builtin` brings into scope. A new name
# fails the test until it is added here.
#
# [tier1-members] The signature of every public or protected member of a [tier1] type, builtin included, that is not
# itself hidden: "<type> :: <kind> <signature>", with the parameter types and modifiers, an optional parameter's
# default, the return type, and static or instance (no parameter names, no generic constraints). Removing or changing
# one reads red by the line; adding one reads red until its line is added. GolibTests writes the lines with
# GO2CS_PUBLIC_SURFACE_MEMBERS=<path>.
#
# A [go-tier2] addition, and any change to [tier1] or [tier1-members] outside the deprecation path, needs a COORD
# ruling, cited in a comment line beside it.

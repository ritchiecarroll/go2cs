Package sha3 implements the SHA-3 fixed-output-length hash functions and the SHAKE variable-output-length functions defined by [FIPS 202](https://doi.org/10.6028/NIST.FIPS.202), as well as the cSHAKE extendable-output-length functions defined by [SP 800-185](https://doi.org/10.6028/NIST.SP.800-185).
